# SPI — справочник регистров (STM32H723VGT6, CMSIS, без HAL)

Источник позиций/ширин бит: `Inc/stm32h723xx.h` (проверено grep по `SPI_CR1_*_Pos`, `SPI_CR2_*_Pos`, `SPI_CFG1_*_Pos`, `SPI_CFG2_*_Pos`, `SPI_IER/SR/IFCR_*_Pos`, `SPI_TXDR/RXDR/CRCPOLY/TXCRC/RXCRC/UDRDR/I2SCFGR_*_Pos` + структ `SPI_TypeDef` для смещений).
Образцов `*_registers.md` в каталоге нет (проверено `glob **/*`), формат повторён по описанию из задачи: заголовок, таблицы `| Биты | Имя | Что делает |`, строки `res` для резервных бит, русский язык.

Базовые адреса (из заголовка: `PERIPH_BASE=0x40000000`, `D2_APB1PERIPH_BASE=PERIPH_BASE`, `D2_APB2PERIPH_BASE=PERIPH_BASE+0x10000`, `D3_APB1PERIPH_BASE=PERIPH_BASE+0x18000000`):

| Модуль | База |
|---|---|
| SPI1 | 0x40013000 (`D2_APB2 + 0x3000`) |
| SPI4 | 0x40013400 (`D2_APB2 + 0x3400`) |
| SPI5 | 0x40015000 (`D2_APB2 + 0x5000`) |
| SPI2 | 0x40003800 (`D2_APB1 + 0x3800`) |
| SPI3 | 0x40003C00 (`D2_APB1 + 0x3C00`) |
| SPI6 | 0x58001400 (`D3_APB1 + 0x1400`) |

Смещения (`SPI_TypeDef`): CR1 0x00, CR2 0x04, CFG1 0x08, CFG2 0x0C, IER 0x10, SR 0x14, IFCR 0x18, TXDR 0x20, RXDR 0x30, CRCPOLY 0x40, TXCRC 0x44, RXCRC 0x48, UDRDR 0x4C, I2SCFGR 0x50. Резерв: 0x1C, 0x24–0x2C, 0x34–0x3C.

Важно H7: это новый SPI (не как F1/F4). Передача master запускается через `CR2.TSIZE` + `CR1.CSTART`, конец — флаг `SR.EOT`. Регистры CFG1/CFG2 настраиваются только при `SPE=0`.

## CFG1 (0x08) — конфигурация 1

| Биты | Имя | Что делает |
|---|---|---|
| 4:0 | DSIZE | Размер кадра минус 1: `0=4 бита … 27=32 бита`. Значения 0–2 зарезервированы. Определяет ширину доступа к TXDR/RXDR |
| 8:5 | FTHLV | Порог FIFO, при котором `TXP/RXP/TXTF`: `0=1 полуслово, 1=2 …` (число 32-битных слов в FIFO до срабатывания) |
| 10:9 | UDRCFG | Что выдавать в slave при underrun: `0=повтор UDRDR, 1=повтор последнего TXDR, 2=0x00000000, 3=0xFFFFFFFF` |
| 12:11 | UDRDET | Когда детектить underrun: `0=начало кадра, 1=конец кадра, 2/3=res` |
| 13 | `res` | Зарезервирован |
| 14 | RXDMAEN | 1 = запрос RX-DMA при `RXP` |
| 15 | TXDMAEN | 1 = запрос TX-DMA при `TXP` |
| 20:16 | CRCSIZE | Размер CRC минус 1 (аналог DSIZE, `0=4 бита … 27=32 бита`) |
| 21 | `res` | Зарезервирован |
| 22 | CRCEN | 1 = аппаратный CRC включён (считается по `CRCPOLY`, размер `CRCSIZE`) |
| 27:23 | `res` | Зарезервированы |
| 30:28 | MBR | Делитель master Baud Rate: `0=/2, 1=/4, 2=/8, 3=/16, 4=/32, 5=/64, 6=/128, 7=/256` от `spi_ker_ck` |
| 31 | `res` | Зарезервирован |

## CFG2 (0x0C) — конфигурация 2

| Биты | Имя | Что делает |
|---|---|---|
| 3:0 | MSSI | Пауза между кадрами в master (число тактов `spi_ker_ck`/`MBR`, `0=нет паузы`) |
| 7:4 | MIDI | Задержка между данными (master inter-data idleness), в тактах baud rate |
| 14:8 | `res` | Зарезервированы |
| 15 | IOSWP | 1 = поменять местами MOSI/MISO (alternate function swap) |
| 16 | `res` | Зарезервирован |
| 18:17 | COMM | Режим связи: `0=full-duplex, 1=simplex TX, 2=simplex RX, 3=half-duplex` (направление — `CR1.HDDIR`) |
| 21:19 | SP | Serial protocol: `0=SPI Motorola, 1=TI, 2..7=I2S и др. (см. I2SCFGR, только если используется I2S)` |
| 22 | MASTER | 1 = master, 0 = slave |
| 23 | LSBFRST | 1 = младшим битом вперёд, 0 = старшим (MSB) |
| 24 | CPHA | Фаза тактов: `0=выборка по первому фронту, 1=по второму` |
| 25 | CPOL | Полярность SCK в простое: `0=0, 1=1` |
| 26 | SSM | 1 = программное управление SS (`SSI`), 0 = аппаратное |
| 27 | `res` | Зарезервирован |
| 28 | SSIOP | Полярность SS: 0 = активный низкий, 1 = активный высокий |
| 29 | SSOE | 1 = master сам выводит SS (NSS output enable) |
| 30 | SSOM | 1 = SS держится между кадрами пока `TSIZE` не исчерпан (master SS output management); 0 = SS дёргается каждый кадр |
| 31 | AFCNTR | 1 = держать GPIO в alternate function даже при `SPE=0` (иначе пины отпускаются) |

## CR1 (0x00) — контроль 1

| Биты | Имя | Что делает |
|---|---|---|
| 0 | SPE | 1 = SPI включён. CFG1/CFG2/I2SCFGR/CRCPOLY менять только при `SPE=0` |
| 7:1 | `res` | Зарезервированы |
| 8 | MASRX | 1 = master одновременно принимает (иначе только передача, для simplex-TX экономии) |
| 9 | CSTART | 1 = старт master-транзакции (взводится софтом, железо держит пока `CTSIZE>0`). Писать только при `SPE=1` |
| 10 | CSUSP | 1 = запрос suspend (пауза master-транзакции). Сброс — флагом `IFCR.SUSPC` |
| 11 | HDDIR | Half-duplex направление: `0=RX, 1=TX` (при `COMM=3`) |
| 12 | SSI | Внутренний уровень SS (при `SSM=1`): задаёт значение NSS софтом |
| 13 | CRC33_17 | 1 = полином CRC длиной 33/17 бит (спецрежим), 0 = обычный `CRCSIZE` |
| 14 | RCRCINI | 1 = сбросить RX-CRC перед транзакцией (инициализировать) |
| 15 | TCRCINI | 1 = сбросить TX-CRC перед транзакцией |
| 16 | IOLOCK | 1 = заблокировать смену пинов (AF lock) до выключения |
| 31:17 | `res` | Зарезервированы |

## CR2 (0x04) — контроль 2 (число кадров)

| Биты | Имя | Что делает |
|---|---|---|
| 15:0 | TSIZE | Число кадров в транзакции master. 0 = бесконечная (до `CSUSP`/выкл). Убывает в `SR.CTSIZE` |
| 31:16 | TSER | Маска слотов TDM (для SP-протоколов с фреймами); 0 = все слоты активны |

## IER (0x10) — разрешение прерываний

| Биты | Имя | Что делает |
|---|---|---|
| 0 | RXPIE | Прерывание по `SR.RXP` (в RX-FIFO ≥ `FTHLV`) |
| 1 | TXPIE | Прерывание по `SR.TXP` (в TX-FIFO ≤ `FTHLV`) |
| 2 | DXPIE | Прерывание по `SR.DXP` (оба условия сразу, full-duplex) |
| 3 | EOTIE | Прерывание по `SR.EOT` (транзакция завершена) |
| 4 | TXTFIE | Прерывание по `SR.TXTF` (TX-FIFO пуст / threshold) |
| 5 | UDRIE | Прерывание по underrun `SR.UDR` |
| 6 | OVRIE | Прерывание по overrun `SR.OVR` |
| 7 | CRCEIE | Прерывание по ошибке CRC `SR.CRCE` |
| 8 | TIFREIE | Прерывание по ошибке кадра TI `SR.TIFRE` |
| 9 | MODFIE | Прерывание по конфликту режима `SR.MODF` |
| 10 | TSERFIE | Прерывание по ошибке числа кадров `SR.TSERF` |
| 31:11 | `res` | Зарезервированы |

## SR (0x14) — статус

| Биты | Имя | Что делает |
|---|---|---|
| 0 | RXP | 1 = в RX-FIFO данных ≥ `FTHLV`, можно читать `RXDR` |
| 1 | TXP | 1 = в TX-FIFO места ≥ `FTHLV`, можно писать `TXDR` |
| 2 | DXP | 1 = одновременно `RXP` и `TXP` (удобно для full-duplex цикла) |
| 3 | EOT | 1 = транзакция завершена (`CTSIZE=0` + последний кадр ушёл). Сброс — `IFCR.EOTC` (или чтение+запись по flow) |
| 4 | TXTF | 1 = TX-FIFO достиг порога/пуст (threshold flag) |
| 5 | UDR | 1 = underrun (нечего было выдать). Сброс — `IFCR.UDRC` |
| 6 | OVR | 1 = overrun (RX переполнен, данные потеряны). Сброс — `IFCR.OVRC` |
| 7 | CRCE | 1 = ошибка CRC. Сброс — `IFCR.CRCEC` |
| 8 | TIFRE | 1 = ошибка TI-кадра. Сброс — `IFCR.TIFREC` |
| 9 | MODF | 1 = mode fault (два master / конфликт NSS). Сброс — `IFCR.MODFC` |
| 10 | TSERF | 1 = ошибка числа слотов/кадров. Сброс — `IFCR.TSERFC` |
| 11 | SUSP | 1 = транзакция приостановлена (`CSUSP` отработан). Сброс — `IFCR.SUSPC` |
| 12 | TXC | 1 = весь TX-конвейер пуст (TXFIFO + сдвиговый регистр). Только чтение, прерывания нет |
| 14:13 | RXPLVL | Сколько 32-битных слов в RX-FIFO сейчас (`0–3`) |
| 15 | RXWNE | 1 = RX-FIFO не пуст (хоть одно слово есть) |
| 31:16 | CTSIZE | Остаток кадров (`TSIZE` минус переданные). Только чтение |
| — | прим. | `RXWNE`/`TXTF`/`RXP`/`TXP` — это уровни FIFO; `EOT/TXC` — конец транзакции. Имя `TIF` из задачи — в заголовке это `TIFRE` (TI frame error), отдельного `TIF` нет |

## IFCR (0x18) — сброс флагов (пиши 1)

| Биты | Имя | Что делает |
|---|---|---|
| 2:0 | `res` | Зарезервированы |
| 3 | EOTC | Запись 1 = сбросить `SR.EOT` |
| 4 | TXTFC | Запись 1 = сбросить `SR.TXTF` |
| 5 | UDRC | Запись 1 = сбросить `SR.UDR` |
| 6 | OVRC | Запись 1 = сбросить `SR.OVR` |
| 7 | CRCEC | Запись 1 = сбросить `SR.CRCE` |
| 8 | TIFREC | Запись 1 = сбросить `SR.TIFRE` |
| 9 | MODFC | Запись 1 = сбросить `SR.MODF` |
| 10 | TSERFC | Запись 1 = сбросить `SR.TSERF` |
| 11 | SUSPC | Запись 1 = сбросить `SR.SUSP` (+ снять `CR1.CSUSP`) |
| 31:12 | `res` | Зарезервированы |

## TXDR (0x20) / RXDR (0x30) — данные

| Регистр | Биты | Имя | Что делает |
|---|---|---|---|
| TXDR | 31:0 | TXDR | Что записал — то уйдёт в сдвиговый регистр. Ширина доступа = `DSIZE`: при `DSIZE≤7` пиши `uint8_t`, при `≤15` — `uint16_t`, при `>15` — `uint32_t`. Запись более широким типом испортит соседние кадры в FIFO |
| RXDR | 31:0 | RXDR | Что пришло из сдвигового регистра. Читать тем же типом, что `DSIZE` (`8/16/32` бита) |

Резервные слова между ними (0x24–0x2C, 0x34–0x3C) не использовать.

## CRCPOLY (0x40) / TXCRC (0x44) / RXCRC (0x48) / UDRDR (0x4C)

| Регистр | Биты | Имя | Что делает |
|---|---|---|---|
| CRCPOLY | 31:0 | CRCPOLY | Полином CRC. Писать при `SPE=0`, длина = `CRCSIZE` (или 33/17 при `CRC33_17=1`) |
| TXCRC | 31:0 | TXCRC | Текущее значение TX-CRC (чтение для контроля; сброс — `CR1.TCRCINI`) |
| RXCRC | 31:0 | RXCRC | Текущее значение RX-CRC (сброс — `CR1.RCRCINI`; несовпадение даёт `SR.CRCE`) |
| UDRDR | 31:0 | UDRDR | Паттерн для выдачи при underrun в slave (если `UDRCFG=0`). Писать при `SPE=0` |

## I2SCFGR (0x50) — конфигурация I2S (только если `CFG2.SP` = I2S)

| Биты | Имя | Что делает |
|---|---|---|
| 0 | I2SMOD | 1 = режим I2S (а не SPI). Менять при `SPE=0` |
| 3:1 | I2SCFG | Роль/направление: `0=slave-TX, 1=slave-RX, 2=master-TX, 3=master-RX, 4..7=full-duplex комбинации` (точное значение — по RM) |
| 5:4 | I2SSTD | Стандарт: `0=Philips, 1=MSB-justified, 2=LSB-justified, 3=PCM` |
| 7:6 | `res` | Зарезервированы (в заголовке: `PCMSYNC` — бит 7, бит 6 — res) |
| 7 | PCMSYNC | Синхронизация PCM: `0=короткий, 1=длинный` (при `I2SSTD=PCM`) |
| 9:8 | DATLEN | Длина данных: `0=16 бит, 1=24 бита, 2=32 бита, 3=res` |
| 10 | CHLEN | Длина канала: `0=16 бит, 1=32 бита` |
| 11 | CKPOL | Полярность тактов в простое: `0=0, 1=1` |
| 12 | FIXCH | 1 = фиксированный канал (для спецрежимов) |
| 13 | WSINV | 1 = инверсия WS (выбор канала L/R наоборот) |
| 14 | DATFMT | 1 = данные выровнены вправо со знаком (иначе без знака/влево) |
| 15 | `res` | Зарезервирован |
| 23:16 | I2SDIV | Делитель аудиотактов (целая часть) |
| 24 | ODD | 1 = нечётный коэффициент (`I2SDIV*2+1`) |
| 25 | MCKOE | 1 = выводить master clock (MCK) |
| 31:26 | `res` | Зарезервированы |

## Алгоритм: master full-duplex (новый flow H7: TSIZE + CSTART + EOT)

1. Выкл: `CR1.SPE = 0`. Дождаться `SPE=0`.
2. Настрой: `CFG1.DSIZE` (напр. `7` = 8 бит), `CFG1.FTHLV=0`, `CFG1.MBR` (делитель от `spi_ker_ck`), `CFG2.MASTER=1`, `CFG2.COMM=0` (full-duplex), `CFG2.SSM=1`, `CFG2.SSIOP/SSOE/SSOM` (обычно `SSOE=1`, `SSOM=1` чтобы SS держался всю пачку), `CPOL/CPHA/LSBFRST` под slave. `CR1.MASRX=1` чтобы принимать одновременно.
3. Вкл: `CR1.SPE = 1`.
4. Сброс флагов: `IFCR = (1<<EOTC)|(1<<TXTFC)|(1<<UDRC)|(1<<OVRC)|(1<<CRCEC)|(1<<TIFREC)|(1<<MODFC)|(1<<TSERFC)|(1<<SUSPC)`.
5. Число кадров: `CR2.TSIZE = N` (число кадров = числу записей в TXDR).
6. Старт: `CR1.CSTART = 1`.
7. Цикл пока `SR.CTSIZE > 0` или `EOT==0`:
   - пока `SR.TXP==1` и есть что слать — пиши `TXDR` (типом по `DSIZE`!);
   - пока `SR.RXP==1` (или `RXWNE==1`) — читай `RXDR` в буфер;
   - ошибки: `UDR/OVR/CRCE/MODF` — обработать и гасить через `IFCR`.
8. Конец: дождаться `SR.EOT==1`, затем дочитать остаток (`пока RXWNE — читай RXDR`), затем `IFCR.EOTC=1`.
9. Останов: `SPE=0` только после `EOT` + `TXC==1` (иначе обрежешь хвост).
10. Suspend (пауза длинной пачки): `CR1.CSUSP=1` → ждать `SR.SUSP==1` → можно дозаписать `TSIZE`/FIFO → `IFCR.SUSPC=1` для продолжения.

Псевдокод (CMSIS):
```c
SPI1->CR1 &= ~(1u << 0);              // SPE=0
SPI1->CFG1 = (7u << 0) | (2u << 28);  // DSIZE=8бит, MBR=/16
SPI1->CFG2 = (1u << 22)|(1u << 26)|(1u << 29)|(1u << 30); // MASTER, SSM, SSOE, SSOM
SPI1->CR1 |= (1u << 8);               // MASRX=1
SPI1->CR1 |= (1u << 0);               // SPE=1
SPI1->IFCR = 0xFFF8u;                 // сброс всех флагов 3..11
SPI1->CR2 = n;                        // TSIZE=n
SPI1->CR1 |= (1u << 9);               // CSTART
while (!(SPI1->SR & (1u << 3))) {     // ждём EOT
    if (SPI1->SR & (1u << 1)) SPI1->TXDR = *tx++;
    if (SPI1->SR & (1u << 0)) *rx++ = SPI1->RXDR;
}
while (SPI1->SR & (1u << 15)) *rx++ = SPI1->RXDR; // дочитать
SPI1->IFCR = (1u << 3);               // EOTC
```
