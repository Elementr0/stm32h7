# EXTI — регистры (STM32H723VGT6)

Внешние прерывания/события, процессорная часть. Сверено с `Inc/stm32h723xx.h`
(`EXTI_TypeDef`, маски `EXTI_*_Pos`). Выбор пина для линий 0–15 — через
SYSCFG_EXTICR1–4 (см. `SYSCFG_registers.md`).

## База и структура

`EXTI_BASE = D3_APB1PERIPH_BASE + 0x0000 = 0x58000000`.
Алиасы из заголовка: `EXTI_D1_BASE = EXTI_BASE + 0x0080` (IMR1/EMR1/PR1…,
Cortex-M7), `EXTI_D2_BASE = EXTI_BASE + 0x00C0`.

| Смещение | Регистр | Назначение |
|----------|---------|------------|
| 0x00 | RTSR1 | Фронт нарастания, линии 0–21 |
| 0x04 | FTSR1 | Фронт спада, линии 0–21 |
| 0x08 | SWIER1 | Программная генерация, линии 0–21 |
| 0x0C | D3PMR1 | Маска пробуждения D3, линии 0–15,19–21,25 |
| 0x10 | D3PCR1L | Выбор очистки D3, линии 0–15 |
| 0x14 | D3PCR1H | Выбор очистки D3, линии 19–21,25 |
| 0x18–0x1C | `res` | Резерв (`RESERVED1[2]`) |
| 0x20 | RTSR2 | Фронт нарастания: линия 49 (бит 17), линия 51 (бит 19) |
| 0x24 | FTSR2 | Фронт спада: линия 49 (бит 17), линия 51 (бит 19) |
| 0x28 | SWIER2 | Программно: линия 49 (бит 17), линия 51 (бит 19) |
| 0x2C | D3PMR2 | Маска D3: биты 2,3,9,16–21 (линии 34,35,41,48–53) |
| 0x30 | D3PCR2L | Очистка D3: линии 34,35,41 |
| 0x34 | D3PCR2H | Очистка D3: линии 48–53 |
| 0x38–0x3C | `res` | Резерв (`RESERVED2[2]`) |
| 0x40 | RTSR3 | Фронт нарастания: линия 85 (бит 21), линия 86 (бит 22) |
| 0x44 | FTSR3 | Фронт спада: линия 85 (бит 21), линия 86 (бит 22) |
| 0x48 | SWIER3 | Программно: линия 85 (бит 21), линия 86 (бит 22) |
| 0x4C | D3PMR3 | Маска D3: бит 24 (линия 88) |
| 0x50 | D3PCR3L | Нет битовых define в заголовке — считать резервом |
| 0x54 | D3PCR3H | Очистка D3: линия 88 (бит 16) |
| 0x58–0x7C | `res` | Резерв (`RESERVED3[10]`) |
| 0x80 | IMR1 | Маска прерываний CPU, линии 0–31 |
| 0x84 | EMR1 | Маска событий CPU, линии 0–31 |
| 0x88 | PR1 | Флаги ожидания, линии 0–21 (сброс записью 1) |
| 0x8C | `res` | Резерв (`RESERVED4`) |
| 0x90 | IMR2 | Маска прерываний: биты 0–11,15–24,26,28–31 |
| 0x94 | EMR2 | Маска событий: биты 0–11,15–24,26,28–31 |
| 0x98 | PR2 | Флаги: бит 17 (линия 49), бит 19 (линия 51) |
| 0x9C | `res` | Резерв (`RESERVED5`) |
| 0xA0 | IMR3 | Маска прерываний: биты 0–14,16,21–27 |
| 0xA4 | EMR3 | Маска событий: биты 0–14,16,21–27 |
| 0xA8 | PR3 | Флаги: бит 20 (линия 84), 21 (85), 22 (86) |

> Отличие от задания: в заголовке есть и третья группа (RTSR3/FTSR3/SWIER3,
> D3PMR3/D3PCR3x, IMR3/EMR3/PR3) — она задокументирована ниже. Отдельных
> регистров вида `CPUIMR/CPUIEMR` нет: доступ CPU идёт через IMRx/EMRx/PRx
> по смещениям 0x80+ (алиас `EXTI_D1`).

Соответствие «бит ↔ линия»: группа 1 — бит n = линия n (0–21);
группа 2 — бит 17 = линия 49, бит 19 = линия 51;
группа 3 — бит 20 = линия 84, бит 21 = линия 85, бит 22 = линия 86.
Линии IMR2/IMR3/EMR2/EMR3: бит n группы 2 = линия 32+n, группы 3 = линия 64+n.

## RTSR1 (0x00) / FTSR1 (0x04) / SWIER1 (0x08)

`TRn_Pos = SWIERn_Pos = n`, n = 0–21 (`EXTI_RTSR1_TR0..TR21_Pos`,
`EXTI_FTSR1_TR0..TR21_Pos`, `EXTI_SWIER1_SWIER0..SWIER21_Pos`,
групповая маска `0x3FFFFF`). 1 — фронт разрешён (RTSR/FTSR);
запись 1 в SWIERn — программный запуск линии n.

| 6 | TR6 / SWIER6 | Линия 6 |
| 7 | TR7 / SWIER7 | Линия 7 |

| 10 | TR10 / SWIER10 | Линия 10 |
| 11 | TR11 / SWIER11 | Линия 11 |
| 12 | TR12 / SWIER12 | Линия 12 |

| 15 | TR15 / SWIER15 | Линия 15 |

## D3PMR1 (0x0C) — маска пробуждения D3

`MRn_Pos`: биты 0–15 (линии 0–15), 19–21 (линии 19–21), 24 (линия 25).
1 — линия будит домен D3.

| Биты | Имя | Что делает |
|------|-----|------------|
| 0–15 | MR0–MR15 | Маска пробуждения линий 0–15 (по 1 биту) |

| 19 | MR19 | Маска пробуждения линии 19 |
| 20 | MR20 | Маска пробуждения линии 20 |
| 21 | MR21 | Маска пробуждения линии 21 |
| 23:22 | `res` | Резерв |
| 24 | MR25 | Маска пробуждения линии 25 |
| 31:25 | `res` | Резерв |

## RTSR2 (0x20) / FTSR2 (0x24) / SWIER2 (0x28) / PR2 (0x98)

Только два бита (`TR_Pos = PR_Pos = 17`, маска `0x5 << 17`):
`TR49/SWIER49/PR49_Pos = 17`, `TR51/SWIER51/PR51_Pos = 19`.
PR2 сбрасывается записью 1.

| Биты | Имя | Что делает |
|------|-----|------------|
| 16:0 | `res` | Резерв |
| 17 | TR49 / SWIER49 / PR49 | Линия 49 |
| 18 | `res` | Резерв |
| 19 | TR51 / SWIER51 / PR51 | Линия 51 |
| 31:20 | `res` | Резерв |

## D3PMR2 (0x2C) / D3PCR2L (0x30) / D3PCR2H (0x34)

D3PMR2 (`MRn_Pos`): бит 2 — линия 34, бит 3 — линия 35, бит 9 — линия 41,
биты 16–21 — линии 48–53; остальные резерв.

5:4 — PCS50, 7:6 — PCS51, 9:8 — PCS52, 11:10 — PCS53, 31:12 — `res`.

## D3PMR3 (0x4C) / D3PCR3H (0x54) / PR3 (0xA8)

D3PMR3: только `MR88_Pos = 24` (линия 88), остальное `res`.
D3PCR3L: битовых define нет — весь регистр `res`.
D3PCR3H: только `PCS88_Pos = 16` (биты 17:16), остальное `res`.
PR3 (`PR_Pos = 20`, маска `0x7 << 20`): `PR84_Pos = 20`, `PR85_Pos = 21`,
`PR86_Pos = 22`; сброс записью 1; остальные биты `res`.

## IMR1 (0x80) / EMR1 (0x84) — маски CPU, линии 0–31

`IMn_Pos = EMn_Pos = n`, n = 0–31, групповая маска `0xFFFFFFFF`.
1 в IMR — прерывание линии разрешено в NVIC; 1 в EMR — событие пробуждает CPU.

| Биты | Имя | Что делает |
|------|-----|------------|
| 0–31 | IM0–IM31 / EM0–EM31 | Маска прерывания / события линий 0–31 (по 1 биту) |

## Как настроить прерывание с пина (линия 0–15)

1. Включить тактирование SYSCFG в RCC и GPIO-порта.
2. Пин в GPIO: `MODER = 00` (вход) + нужный PUPDR.
3. SYSCFG_EXTICR[n/4]: поле EXTI_n = код порта (0=A, 1=B … 0xA=K, без 8=I).
4. EXTI_RTSR1 и/или EXTI_FTSR1: бит n = 1 (фронт).
5. EXTI_PR1: сбросить флаг записью 1 в бит n.
6. EXTI_IMR1: бит n = 1 (разрешить прерывание).
7. NVIC: разрешить соответствующий IRQ (`EXTI0_IRQn` … `EXTI15_10_IRQn`)
   и выставить приоритет; в обработчике снова гасить флаг в PR1 записью 1.

Для пробуждения вместо прерывания — бит n в EMR1 (событие) вместо IMR1.
Для домена D3 — дополнительно бит линии в D3PMRx и источник в D3PCRx.
