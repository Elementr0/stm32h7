# USART STM32H7 — все регистры, все биты

Полный справочник по регистрам USART/UART (RM0468). Проверено по `Inc/stm32h723xx.h`.
Одинаково для всех инстансов, меняются только базовые адреса.

Базы: USART1 `0x40011000`, USART6 `0x40011400`, USART2 `0x40004400`,
USART3 `0x40004800`, UART4 `0x40004C00`, UART5 `0x40005000`
(наличие выводов зависит от корпуса — для LQFP100 смотри даташит).

Кратко одной строкой:

| Регистр | Смещение | Назначение |
|---|---|---|
| CR1 | 0x00 | Вкл/выкл, длина слова, паритет, TE/RE, оверсемплинг, прерывания, FIFO вкл |
| CR2 | 0x04 | Стоп-биты, синхронный/LIN/SPI-slave режимы, инверсии, автобод, таймаут |
| CR3 | 0x08 | RTS/CTS, DMA, полудуплекс, RS-485, IrDA, смарт-карты, пороги FIFO |
| BRR | 0x0C | Делитель бодрейта |
| GTPR | 0x10 | Делитель для CK и guard time смарт-карт |
| RTOR | 0x14 | Таймаут приёмника и длина блока |
| RQR | 0x18 | Программные команды (break, сброс RX/TX, автобод, mute) |
| ISR | 0x1C | Флаги состояния (только чтение) |
| ICR | 0x20 | Сброс флагов (запись 1) |
| RDR | 0x24 | Принятый байт (чтение) |
| TDR | 0x28 | Байт на передачу (запись) |
| PRESC | 0x2C | Предделитель тактов ядра |

## Общие правила

1. **Формат кадра настраивается только при `UE=0`**: M0/M1, PCE/PS, OVER8,
   STOP, CLKEN/CPOL/CPHA, SWAP, инверсии, MSBFIRST, PRESC, BRR, GTPR, RTOR,
   FIFOEN, DEM/DEP, SCEN. Разрешения прерываний/DMA, TE/RE/UE и команды RQR —
   в любой момент.
2. **Порядок инициализации**: такты RCC → пины GPIO/AF → `UE=0` →
   CR1/CR2/CR3 → PRESC → BRR → `UE=1` → ждать `TEACK+REACK` →
   сбросить ошибки через ICR → работа.
3. **Такты ядра** выбираются в RCC (по сбросу везде `pclk`, т.е. частота шины):
   `D2CCIP2R.USART16SEL` — для USART1/6; `D2CCIP1R.USART234578SEL` —
   для USART2/3 и UART4/5/7/8. Значения: 000=pclk, 001=pll2_q, 010=pll3_q,
   011=hsi, 100=csi, 101=lse.
4. Сбросные значения всех регистров — 0, кроме `ISR = 0xC0`
   (после сброса установлены `TXE` и `TC` — передатчик пуст).

## CR1 (0x00) — главный управляющий, rw

| Биты | Имя | Что делает |
|---|---|---|
| 0 | UE | Включение USART. После установки ждать TEACK/REACK в ISR |
| 1 | UESM | Работа в Stop-режиме + пробуждение (нужен источник тактов, живой в Stop) |
| 2 | RE | Приёмник вкл/выкл |
| 3 | TE | Передатчик вкл/выкл |
| 4 | IDLEIE | Прерывание по простою линии (IDLE) |
| 5 | RXNEIE_RXFNEIE | Прерывание: данные приняты / FIFO достиг порога |
| 6 | TCIE | Прерывание по концу передачи (TC) |
| 7 | TXEIE_TXFNFIE | Прерывание: можно писать / FIFO ниже порога |
| 8 | PEIE | Прерывание по ошибке паритета |
| 9 | PS | Паритет: 0=even, 1=odd |
| 10 | PCE | Контроль чётности вкл (занимает 9-й бит кадра) |
| 11 | WAKE | Пробуждение из mute: 0=по idle-линии, 1=по адресной метке |
| 12 | M0 | Длина слова, младший бит (см. M1) |
| 13 | MME | Mute mode: игнорировать трафик до пробуждающего события |
| 14 | CMIE | Прерывание по совпадению символа с ADD (CMF) |
| 15 | OVER8 | Оверсемплинг: 0=x16, 1=x8 (в LIN/Smartcard/IrDA только x16) |
| 20:16 | DEDT[4:0] | RS-485: задержка снятия DE после стоп-бита, в тактах ядра |
| 25:21 | DEAT[4:0] | RS-485: задержка от подъёма DE до стартового бита, в тактах ядра |
| 26 | RTOIE | Прерывание по таймауту приёмника (RTOF) |
| 27 | EOBIE | Прерывание по концу блока смарт-карты (EOBF) |
| 28 | M1 | Длина слова, старший бит. M1M0: 00=8 бит, 01=9 бит, 10=7 бит, 11=резерв |
| 29 | FIFOEN | Режим 8-байтных FIFO (только при UE=0). Меняет смысл флагов TXE/RXNE |
| 30 | TXFEIE | Прерывание: FIFO передачи пуст |
| 31 | RXFFIE | Прерывание: FIFO приёма полон |

## CR2 (0x04) — кадр и спецрежимы, rw

| Биты | Имя | Что делает |
|---|---|---|
| 0 | SLVEN | Режим SPI slave (синхронный, такты от мастера на вывод CK) |
| 2:1 | — | Резерв |
| 3 | DIS_NSS | 1=игнорировать NSS в SPI-slave |
| 4 | ADDM7 | Адрес узла: 0=4-битный (ADD[3:0]), 1=8-битный (ADD[7:0]) |
| 5 | LBDL | Длина LIN break: 0=10 бит, 1=11 бит |
| 6 | LBDIE | Прерывание по LIN break (LBDF) |
| 7 | — | Резерв |
| 8 | LBCL | Выдать импульс CK на последнем бите (Smartcard) |
| 9 | CPHA | Фаза тактов CK (синхронный/Smartcard/SPI режим) |
| 10 | CPOL | Полярность CK в простое: 0=низкий, 1=высокий |
| 11 | CLKEN | Вывод тактов на пин CK (синхронный режим, Smartcard) |
| 13:12 | STOP[1:0] | Стоп-биты: 00=1, 01=0.5, 10=2, 11=1.5 |
| 14 | LINEN | Режим LIN |
| 15 | SWAP | Поменять TX и RX местами внутри (удобно при трассировке платы) |
| 16 | RXINV | Инверсия уровня линии RX |
| 17 | TXINV | Инверсия уровня линии TX |
| 18 | DATAINV | Инверсия бит данных (XOR) |
| 19 | MSBFIRST | 1=старшим битом вперёд (по умолчанию младшим, LSB first) |
| 20 | ABREN | Автобод вкл (скорость измеряется по первому кадру, результат — в BRR) |
| 22:21 | ABRMODE[1:0] | По чему мерить: 00=стартовый бит, 01=спадающий фронт, 10=кадр 0x7F, 11=кадр 0x55 |
| 23 | RTOEN | Таймаут приёмника вкл (порог — RTOR.RTO, флаг — RTOF) |
| 31:24 | ADD[7:0] | Адрес узла (multiprocessor) и эталон для совпадения символа CMF |

## CR3 (0x08) — flow control, DMA, драйверы, FIFO, rw

| Биты | Имя | Что делает |
|---|---|---|
| 0 | EIE | Прерывание по ошибкам FE/NE/ORE (нужно для DMA/multiprocessor) |
| 1 | IREN | Режим IrDA вкл |
| 2 | IRLP | IrDA пониженной мощности (короткий импульс 3/16) |
| 3 | HDSEL | Полудуплекс: TX и RX замыкаются внутри на один провод |
| 4 | NACK | Смарт-карты: слать NACK при ошибке паритета |
| 5 | SCEN | Режим смарт-карт вкл (требует CLKEN, 8 бит + паритет, 1.5/0.5 стопа) |
| 6 | DMAR | Запрос DMA на приём |
| 7 | DMAT | Запрос DMA на передачу |
| 8 | RTSE | RTS flow control (останавливаем чужой передатчик) |
| 9 | CTSE | CTS flow control (нас останавливают) |
| 10 | CTSIE | Прерывание по смене CTS |
| 11 | ONEBIT | Выборка бита: 0=3 сэмпла + мажоритарка (помехоустойчиво), 1=1 сэмпл (для высоких скоростей) |
| 12 | OVRDIS | 1=переполнение не поднимает ORE, новые данные молча затирают RDR |
| 13 | DDRE | 1=при ошибке приёма DMA НЕ отключать (по умолчанию 0=отключать) |
| 14 | DEM | RS-485: вывод RTS работает как Driver Enable |
| 15 | DEP | Полярность DE: 0=активный высокий, 1=активный низкий |
| 16 | — | Резерв |
| 19:17 | SCARCNT[2:0] | Смарт-карты: число автоповторов при NACK (0–7) |
| 21:20 | WUS[1:0] | Источник пробуждения из Stop: 00=адрес/idle (по WAKE), 10=стартовый бит, 11=RXNE |
| 22 | WUFIE | Прерывание по пробуждению (WUF) |
| 23 | TXFTIE | Прерывание: TX FIFO ниже порога |
| 24 | TCBGTIE | Прерывание TCBGT (передача окончена до guard time, Smartcard) |
| 27:25 | RXFTCFG[2:0] | Порог RX FIFO: 000=1/8, 001=1/4, 010=1/2, 011=3/4, 100=7/8, 101=8/8 |
| 28 | RXFTIE | Прерывание: RX FIFO достиг порога |
| 31:29 | TXFTCFG[2:0] | Порог TX FIFO (кодировка та же, что у RXFTCFG) |

## BRR (0x0C) — делитель бодрейта, rw

Целое значение регистра (мантисса и дробь уже упакованы железом):

- `OVER8=0`: `BRR = round(f_ck / baud)`
- `OVER8=1`: `BRR = round(2·f_ck / baud)` со сброшенным битом 0 (дробь в битах 3:1)

Пример: 64000000/115200 = 555.6 → 556 = `0x22C` (реальные 115107 бод, ошибка 0.08%).
Писать при `UE=0`. При автободе BRR заполняет само железо.

## GTPR (0x10) — предделитель и guard time, rw, только при UE=0

| Биты | Имя | Что делает |
|---|---|---|
| 7:0 | PSC[7:0] | Делитель частоты ядра для выхода тактов CK (Smartcard) и кодера IrDA |
| 15:8 | GT[7:0] | Guard time: пауза в бод-интервалах после передачи (Smartcard) |

Для обычного UART остаётся 0.

## RTOR (0x14) — таймаут и длина блока, rw

| Биты | Имя | Что делает |
|---|---|---|
| 23:0 | RTO[23:0] | Порог таймаута в битовых интервалах. Включается CR2.RTOEN, срабатывание — флаг RTOF. Удобно для приёма пакетов переменной длины: тишина дольше порога = конец пакета |
| 31:24 | BLEN[7:0] | Длина блока в байтах (Smartcard), конец — флаг EOBF |

## RQR (0x18) — программные команды, w

Запись `1` выполняет команду, бит самоочищается, чтение всегда даёт 0:

| Бит | Имя | Команда |
|---|---|---|
| 0 | ABRRQ | Перезапустить автобод (сбрасывает ABRF/ABRE) |
| 1 | SBKRQ | Послать break — уронить линию в 0 (флаг SBKF на время) |
| 2 | MMRQ | Уйти в mute (RWU=1, трафик игнорируется до пробуждения) |
| 3 | RXFRQ | Сбросить приёмник: выкинуть данные, снять RXNE |
| 4 | TXFRQ | Сбросить передатчик: выкинуть очередь, поднять TXE |

## ISR (0x1C) — флаги состояния, только чтение

| Бит | Имя | Значение и как гасится |
|---|---|---|
| 0 | PE | Ошибка паритета (данные при этом лежат в RDR) → ICR.PECF |
| 1 | FE | Нет стоп-бита → ICR.FECF |
| 2 | NE | Шум (сэмплы не сошлись) → ICR.NECF |
| 3 | ORE | Переполнение: новый байт пришёл, старый не забрали → ICR.ORECF. Пока висит — данные теряются |
| 4 | IDLE | Простой линии дольше кадра (конец пакета) → ICR.IDLECF |
| 5 | RXNE_RXFNE | Байт принят / RX FIFO достиг порога → чтением RDR |
| 6 | TC | Кадр полностью ушёл вместе со стоп-битом → записью в TDR или ICR.TCCF |
| 7 | TXE_TXFNF | Можно писать в TDR / TX FIFO ниже порога → записью в TDR |
| 8 | LBDF | Принят LIN break → ICR.LBDCF |
| 9 | CTSIF | Изменился CTS → ICR.CTSCF |
| 10 | CTS | Текущий уровень входа CTS |
| 11 | RTOF | Сработал таймаут → ICR.RTOCF |
| 12 | EOBF | Конец блока (Smartcard) → ICR.EOBCF |
| 13 | UDR | Underrun в SPI-slave: мастер тактирует, а данных в TDR нет → ICR.UDRCF |
| 14 | ABRE | Ошибка автобода → запросом ABRRQ |
| 15 | ABRF | Автобод завершён, BRR готов → запросом ABRRQ |
| 16 | BUSY | Идёт приём (линия активна). Проверять перед уходом в Stop |
| 17 | CMF | Принятый символ совпал с ADD → ICR.CMCF |
| 18 | SBKF | Идёт передача break (послан через SBKRQ) |
| 19 | RWU | Приёмник в mute (снимается железом при пробуждающем событии) |
| 20 | WUF | Пробуждение из Stop → ICR.WUCF |
| 21 | TEACK | Железо подтверждает: передатчик включился |
| 22 | REACK | Железо подтверждает: приёмник включился |
| 23 | TXFE | TX FIFO пуст (только в FIFO-режиме) |
| 24 | RXFF | RX FIFO полон (только в FIFO-режиме) |
| 25 | TCBGT | Передача окончена с учётом guard time (Smartcard) → ICR.TCBGTCF |
| 26 | RXFT | RX FIFO достиг порога |
| 27 | TXFT | TX FIFO ниже порога |

## ICR (0x20) — сброс флагов, w1c

Запись `1` гасит соответствующий флаг ISR, запись `0` ничего не делает:

| Бит | Имя | Гасит |
|---|---|---|
| 0 | PECF | PE |
| 1 | FECF | FE |
| 2 | NECF | NE |
| 3 | ORECF | ORE |
| 4 | IDLECF | IDLE |
| 5 | TXFECF | TXFE |
| 6 | TCCF | TC |
| 7 | TCBGTCF | TCBGT |
| 8 | LBDCF | LBDF |
| 9 | CTSCF | CTSIF |
| 11 | RTOCF | RTOF |
| 12 | EOBCF | EOBF |
| 13 | UDRCF | UDR |
| 17 | CMCF | CMF |
| 20 | WUCF | WUF |

ABRE/ABRF гасятся только запросом ABRRQ, SBKF/RWU/BUSY/TEACK/REACK/TXFE/RXFF/RXFT/TXFT —
железом по ходу работы, RXNE/TXE — обращением к RDR/TDR.

## RDR (0x24) — приём, только чтение

Биты `RDR[8:0]` — принятые данные (9-й бит нужен при слове 9 бит или принятом паритете).
Каждое чтение забирает один байт и гасит RXNE (в FIFO-режиме флаг гаснет, когда данных
больше нет). При висящем ORE сначала гаси ошибку через ICR, иначе данные битые.

## TDR (0x28) — передача, запись

Биты `TDR[8:0]` — байт на передачу. Запись гасит TXE и ставит байт в очередь;
железо само добавит старт/паритет/стоп по настройкам CR1/CR2.

## PRESC (0x2C) — предделитель ядра, rw, только при UE=0

`PRESCALER[3:0]` делит kernel clock до формулы BRR:

| Значение | Деление | Значение | Деление |
|---|---|---|---|
| 0000 | /1 | 0110 | /12 |
| 0001 | /2 | 0111 | /16 |
| 0010 | /4 | 1000 | /32 |
| 0011 | /6 | 1001 | /64 |
| 0100 | /8 | 1010 | /128 |
| 0101 | /10 | 1011 | /256 |

12–15 зарезервированы. Нужен, когда шина быстрая, а бодрейт низкий
(без него BRR бы не хватило разрядности).

## Что использует наше эхо (сводка)

Такты: HSE 25 МГц → PLL1 (DIVM=5, DIVN=110, DIVP=1) → SYSCLK 550 МГц,
HCLK 275, PCLK2 137.5 МГц. `CR1 = TE|RE (0x0D)`, `CR2 = 0`, `CR3 = 0`,
`PRESC = 0`, `BRR = 137500000/115200 = 1194 = 0x4AA`,
затем `UE=1` + ожидание `TEACK+REACK`. Работа: `TXE→TDR`, `RDR→RXNE`,
ошибки `ORE/FE/NE → ICR + flush RDR`. MCO1 (PA8) = PLL1_Q/15 = 1.145833 МГц
для проверки осциллографом, плюс SysTick-heartbeat 1 с на PE3.
Всё остальное выше — на будущее.
