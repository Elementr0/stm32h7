# Разгон H723 до 550 МГц: алгоритм от 64 до 550

Исходное состояние после сброса: HSI 64 МГц, все делители /1,
VOS — сбросная, Flash — сбросные задержки. Цель: SYSCLK 550 / HCLK 275 /
PCLK 137.5. Код — `SystemClock_550MHz()` в `Src/system_stm32h7xx.c`.
Порядок менять нельзя: напряжение → задержки флеша → генераторы → PLL →
переключение. На любом таймауте — возврат 0 (в main это быстрый блинк PE3).

## Шаг 0. Что считаем заранее (HSE = 25 МГц, плата WeAct)

- Опора PLL обязана быть 1–16 МГц → `DIVM = 5` → 25/5 = 5 МГц.
- VCO обязан попасть в 128–560 (VCOSEL=0) → `DIVN = 110` → 5×110 = 550 МГц.
- SYSCLK = VCO/DIVP → `DIVP = 1` → 550 МГц.
- HCLK ≤ 275 → `HPRE = /2` → 275 МГц. PCLK ≤ 137.5 → все PPRE = /2.
- MCO для проверки: `DIVQ = 32` → PLL1_Q = 17.1875 МГц, MCO-делитель /15 →
  **1.145833 МГц** на PA8.

## Шаг 1. Питание: VOS0

```
PWR->CR3 |= LDOEN;          // LDO включён (на H723 без вариантов)
PWR->D3CR &= ~VOS;          // VOS = 00 -> Scale 0
ждать VOSRDY (D3CR.13)      // напряжение реально поднялось
```

Без Scale0 частота 550 запрещена. Битов тактов PWR на H723 нет —
PWR доступен всегда. Подробности — `PWR_registers.md`.

## Шаг 2. Flash: задержки ДО разгона

```
FLASH->ACR = LATENCY(7) | WRHIGHFREQ(3);   // = 0x37
```

На 64 МГц лишние WS безвредны, а после переключения без них чтение рвалось бы.
Подробности — `FLASH_registers.md`.

## Шаг 3. Кварц

```
RCC->CR |= HSEON;
ждать HSERDY (с таймаутом!) // нет флага = нет кварца -> возврат 0
```

HSEBYP не трогаем (0 = кварц, а не внешний меандр).

## Шаг 4. Делители шин (ещё на старой частоте — безопасно)

```
D1CFGR:  HPRE=/2, D1PPRE=/2
D2CFGR:  D2PPRE1=/2, D2PPRE2=/2     // PCLK2=137.5 пойдет в USART1
D3CFGR:  D3PPRE=/2
```

Кодировки: HPRE /2 = `0x8`, PPRE /2 = `0x4`. D1CPRE (делитель CPU) не трогаем —
там сбросный /1, CPU = SYSCLK.

## Шаг 5. Конфигурация PLL1 (PLL выключен — иначе записи запрещены)

```
PLLCKSELR: PLLSRC = HSE(10), DIVM1 = 5        // опора 5 МГц
PLLCFGR:   VCOSEL = 0 (128..560), RGE = 10 (опора 4..8 МГц),
           DIVP1EN = 1, DIVQ1EN = 1           // выходы P (ядро) и Q (MCO)
PLL1DIVR:  DIVN1 = 109 (x110!), DIVP1 = 0 (/1!), DIVQ1 = 31 (/32!)
```

Ловушка HAL: в регистрах лежат N−1/P−1/Q−1/R−1, а DIVM — прямое значение.
Сверено с `stm32h7xx_hal_rcc.c` (`PLLN - 1U`, `PLLQ - 1U`).

## Шаг 6. Старт PLL и переключение

```
RCC->CR |= PLL1ON;
ждать PLL1RDY (с таймаутом)
RCC->CFGR: SW = 011 (PLL1);
ждать SWS == 011                       // теперь SYSCLK = 550
SystemCoreClock = 275000000 (HCLK!)
```

## Шаг 7. MCO1 на PA8 для осциллографа

```
GPIOA: такты (AHB4ENR), PA8 в AF, AFR = AF0 (функция MCO1), скорость max
CFGR: MCO1PRE = 15 (/15), MCO1 = 011 (PLL1_Q)
```

Итог на пине: 550/32/15 = 1.145833 МГц, меандр 3.3В.

## Шаг 8. Проверка, что всё взлетело (без веры на слово)

1. `RCC->CR`: биты HSERDY(17) и PLL1RDY(25) = 1.
2. `RCC->CFGR` по адресу `0x58024410` (внимание: на H723 это смещение 0x10,
   а не 0x08!): правильное значение `0x00FC001B` (SW=PLL1, SWS=PLL1,
   MCO1=PLL1_Q, MCO1PRE=/15).
3. `USART1->BRR` должен быть `0x4AA` (пересчитан под PCLK2=137.5).
4. Эхо на 115200 идёт бит в бит (лучшее доказательство: при неверном PCLK
   бодрейт уплыл бы и хост видел бы мусор).
5. Осциллограф на PA8: 1.145833 МГц. Светодиод PE3: ровно 1 вспышка в секунду
   (SysTick от HCLK — засекается телефоном: 30 вспышек = 60 с).

## Если что-то пошло не так

| Симптом | Причина |
|---|---|
| Быстрый блинк PE3 после прошивки | HSE не завёлся (HSERDY=0): нет кварца, не та частота, плохой контакт OSC_IN/OUT |
| Зависание на `while SWS` | SW записали, а PLL не залочена (проверь RGE/VCOSEL/DIVM под реальную опору) |
| HardFault сразу после переключения | Забыл LATENCY или VOS (читаешь флеш быстрее, чем она может) |
| Эхо мусором, MCO мимо | PCLK не 137.5: проверь HPRE/PPRE и источник ядра USART (сброс = pclk) |
| `LIBUSB_ERROR_ACCESS` при прошивке | MiniE подвис — передёрнуть USB |
