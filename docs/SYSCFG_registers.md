# SYSCFG — регистры (STM32H723VGT6)

Системная конфигурация. Сверено с `Inc/stm32h723xx.h` (`SYSCFG_TypeDef`,
маски `SYSCFG_*_Pos`).

## База и структура

`SYSCFG_BASE = D3_APB1PERIPH_BASE + 0x0400 = 0x58000400`.

| Смещение | Регистр | Назначение |
|----------|---------|------------|
| 0x00 | — | Резерв (`RESERVED1`) |
| 0x04 | PMCR | I2C Fast-mode Plus, бустер, EPIS, сплит PA0/PA1/PC2/PC3 |
| 0x08 | EXTICR1 | Выбор порта для EXTI 0–3 |
| 0x0C | EXTICR2 | Выбор порта для EXTI 4–7 |
| 0x10 | EXTICR3 | Выбор порта для EXTI 8–11 |
| 0x14 | EXTICR4 | Выбор порта для EXTI 12–15 |
| 0x18 | CFGR | Локи ECC/флагов (PVDL…AXISRAML) |
| 0x1C | — | Резерв (`RESERVED2`) |
| 0x20 | CCCSR | Компенсационная ячейка: управление/статус |
| 0x24 | CCVR | Компенсационная ячейка: измеренные значения |
| 0x28 | CCCR | Компенсационная ячейка: ручной код |
| 0x2C | — | Резерв (`RESERVED3`) |
| 0x30 | ADC2ALT | Альтернативное подключение входов ADC2 |
| 0x34–0x120 | — | Резерв (`RESERVED4[60]`) |
| 0x124 | PKGR | Тип корпуса (только чтение) |
| 0x128–0x2FC | — | Резерв (`RESERVED5[118]`) |
| 0x300–0x31C | UR0–UR7 | Опционные слова flash (защита, адреса, области) |
| 0x320–0x328 | — | Резерв (`RESERVED6[3]`, UR8–UR10 отсутствуют) |
| 0x32C–0x348 | UR11–UR18 | Опционные слова flash (IWDG, secure, сбросы, заморозка) |

> Отличия от задания: регистров MEMRMP и PMC в заголовке НЕТ — вместо них
> один регистр PMCR (0x04). Регистр ADC2ALT существует (0x30). Дополнительно
> в заголовке есть PKGR и UR0–UR7/UR11–UR18 — они задокументированы ниже,
> т.к. задание требует «только то, что есть в заголовке».

## PMCR (0x04) — конфигурация периферии

| Биты | Имя | Что делает |
|------|-----|------------|
| 0 | I2C1_FMP | 1 — Fast-mode Plus на I2C1 |
| 1 | I2C2_FMP | 1 — Fast-mode Plus на I2C2 |
| 2 | I2C3_FMP | 1 — Fast-mode Plus на I2C3 |
| 3 | I2C4_FMP | 1 — Fast-mode Plus на I2C4 |
| 4 | I2C_PB6_FMP | 1 — Fast-mode Plus на PB6 |
| 5 | I2C_PB7_FMP | 1 — Fast-mode Plus на PB7 |
| 6 | I2C_PB8_FMP | 1 — Fast-mode Plus на PB8 |
| 7 | I2C_PB9_FMP | 1 — Fast-mode Plus на PB9 |
| 8 | BOOSTEN | 1 — включить бустер аналоговых ключей |
| 9 | BOOSTVDDSEL | Источник бустера: 0 — VDD, 1 — VDDA |
| 10 | I2C5_FMP | 1 — Fast-mode Plus на I2C5 |
| 20:11 | `res` | Резерв |
| 23:21 | EPIS_SEL[2:0] | Выбор интерфейса ETH PHY (MII/RMII…) |
| 24 | PA0SO | 1 — развязать PA0 (аналоговый ключ открыт) |
| 25 | PA1SO | 1 — развязать PA1 |
| 26 | PC2SO | 1 — развязать PC2 |
| 27 | PC3SO | 1 — развязать PC3 |
| 31:28 | `res` | Резерв |

## EXTICR1 (0x08) – EXTICR4 (0x14) — выбор порта для EXTI

По 4 бита на линию: `EXTIn_Pos = 4*(n mod 4)` (0, 4, 8, 12), маска `0xF`.
Коды портов из заголовка (`SYSCFG_EXTICRn_EXTIn_Px`): 0=A, 1=B, 2=C, 3=D,
4=E, 5=F, 6=G, 7=H, 9=J, 0xA=K (8=I пропущено — порта I нет).

| Биты | Имя | Что делает |
|------|-----|------------|
| 3:0 | EXTI0 (EXTICR1) | Порт для линии 0 |
| 7:4 | EXTI1 (EXTICR1) | Порт для линии 1 |
| 11:8 | EXTI2 (EXTICR1) | Порт для линии 2 |
| 15:12 | EXTI3 (EXTICR1) | Порт для линии 3 |
| 31:16 | `res` | Резерв |
| 3:0 | EXTI4 (EXTICR2) | Порт для линии 4 |
| 7:4 | EXTI5 (EXTICR2) | Порт для линии 5 |
| 11:8 | EXTI6 (EXTICR2) | Порт для линии 6 |
| 15:12 | EXTI7 (EXTICR2) | Порт для линии 7 |
| 31:16 | `res` | Резерв |
| 3:0 | EXTI8 (EXTICR3) | Порт для линии 8 |
| 7:4 | EXTI9 (EXTICR3) | Порт для линии 9 |
| 11:8 | EXTI10 (EXTICR3) | Порт для линии 10 |
| 15:12 | EXTI11 (EXTICR3) | Порт для линии 11 |
| 31:16 | `res` | Резерв |
| 3:0 | EXTI12 (EXTICR4) | Порт для линии 12 |
| 7:4 | EXTI13 (EXTICR4) | Порт для линии 13 |
| 11:8 | EXTI14 (EXTICR4) | Порт для линии 14 |
| 15:12 | EXTI15 (EXTICR4) | Порт для линии 15 |
| 31:16 | `res` | Резерв |

## CFGR (0x18) — локи флагов ECC/сбоев (w1s)

Каждый бит — 1 включает вывод соответствующего флага на ножку/прерывание
(защёлкивается до сброса). Позиции из заголовка:

| Биты | Имя | Что делает |
|------|-----|------------|
| 1:0 | `res` | Резерв |
| 2 | PVDL | Лок выхода PVD |
| 3 | FLASHL | Лок двойной ECC-ошибки flash |
| 5:4 | `res` | Резерв |
| 6 | CM7L | Лок LOCKUP Cortex-M7 (HardFault) |
| 7 | BKRAML | Лок двойной ECC-ошибки backup SRAM |
| 8 | `res` | Резерв |
| 9 | SRAM4L | Лок двойной ECC-ошибки SRAM4 |
| 10 | `res` | Резерв |
| 11 | SRAM2L | Лок двойной ECC-ошибки SRAM2 |
| 12 | SRAM1L | Лок двойной ECC-ошибки SRAM1 |
| 13 | DTCML | Лок двойной ECC-ошибки DTCM |
| 14 | ITCML | Лок двойной ECC-ошибки ITCM |
| 15 | AXISRAML | Лок двойной ECC-ошибки AXI-SRAM |
| 31:16 | `res` | Резерв |

## CCCSR (0x20) — компенсационная ячейка, управление/статус

| Биты | Имя | Что делает |
|------|-----|------------|
| 0 | EN | 1 — включить ячейку компенсации I/O |
| 1 | CS | Выбор кода: 0 — из CCVR (авто), 1 — из CCCR (ручной) |
| 7:2 | `res` | Резерв |
| 8 | READY | 1 — ячейка готова (только чтение) |
| 15:9 | `res` | Резерв |
| 16 | HSLV | 1 — высокоскоростной режим при низком напряжении |
| 31:17 | `res` | Резерв |

## CCVR (0x24) — измеренные коды компенсации (только чтение)

| Биты | Имя | Что делает |
|------|-----|------------|
| 3:0 | NCV[3:0] | Код компенсации NMOS |
| 7:4 | PCV[3:0] | Код компенсации PMOS |
| 31:8 | `res` | Резерв |

## CCCR (0x28) — ручной код компенсации

| Биты | Имя | Что делает |
|------|-----|------------|
| 3:0 | NCC[3:0] | Ручной код NMOS (при CCCSR.CS=1) |
| 7:4 | PCC[3:0] | Ручной код PMOS (при CCCSR.CS=1) |
| 31:8 | `res` | Резерв |

Порядок включения компенсации (H7): подать VDD, `CCCSR.EN=1`, ждать
`CCCSR.READY=1`, затем использовать高速-выводы (Ethernet, OCTOSPI, SDMMC).

## ADC2ALT (0x30) — альтернативные входы ADC2

| Биты | Имя | Что делает |
|------|-----|------------|
| 0 | ADC2_ROUT0 | 1 — VBAT/4 на V_INP[16] ADC2 |
| 1 | ADC2_ROUT1 | 1 — V_REFINT на V_INP[17] ADC2 |
| 31:2 | `res` | Резерв |

## PKGR (0x124) — тип корпуса (только чтение)

| Биты | Имя | Что делает |
|------|-----|------------|
| 3:0 | PKG[3:0] | Код корпуса (расшифровка — в даташите) |
| 31:4 | `res` | Резерв |

## UR0–UR7 (0x300–0x31C) — опционные слова flash, часть 1

Значения прошиты в option bytes; читаются как обычные регистры.

| Биты | Имя | Что делает |
|------|-----|------------|
| 15:0 (UR0) | `res` | Резерв (младшая половина без define) |
| 23:16 (UR0) | RDP[7:0] | Уровень readout protection |
| 31:24 (UR0) | `res` | Резерв |
| 1:0 (UR2) | BORH[1:0] | Порог Brown-Out Reset (high) |
| 15:2 (UR2) | `res` | Резерв |
| 31:16 (UR2) | BOOT_ADD0[15:0] | Boot-адрес 0 ядра |
| 15:0 (UR3) | BOOT_ADD1[15:0] | Boot-адрес 1 ядра |
| 31:16 (UR3) | `res` | Резерв |
| 15:0 (UR4) | `res` | Резерв |
| 16 (UR4) | MEPAD_BANK1 | 1 — mass-erase защищённой области bank1 запрещён |
| 31:17 (UR4) | `res` | Резерв |
| 0 (UR5) | MESAD_BANK1 | 1 — mass-erase secured area bank1 запрещён |
| 15:1 (UR5) | `res` | Резерв |
| 23:16 (UR5) | WRPN_BANK1[7:0] | Write protection секторов bank1 |
| 31:24 (UR5) | `res` | Резерв |
| 11:0 (UR6) | PABEG_BANK1[11:0] | Начало protected area bank1 |
| 15:12 (UR6) | `res` | Резерв |
| 27:16 (UR6) | PAEND_BANK1[11:0] | Конец protected area bank1 |
| 31:28 (UR6) | `res` | Резерв |
| 11:0 (UR7) | SABEG_BANK1[11:0] | Начало secured area bank1 |
| 15:12 (UR7) | `res` | Резерв |
| 27:16 (UR7) | SAEND_BANK1[11:0] | Конец secured area bank1 |
| 31:28 (UR7) | `res` | Резерв |

UR1 без битовых define в заголовке — целиком `res`.

## UR11–UR18 (0x32C–0x348) — опционные слова flash, часть 2

| Биты | Имя | Что делает |
|------|-----|------------|
| 15:0 (UR11) | `res` | Резерв |
| 16 (UR11) | IWDG1M | Режим IWDG1: 0 — hardware, 1 — software |
| 31:17 (UR11) | `res` | Резерв |
| 15:0 (UR12) | `res` | Резерв |
| 16 (UR12) | SECURE | 1 — secure-режим активен |
| 31:17 (UR12) | `res` | Резерв |
| 1:0 (UR13) | SDRS[1:0] | Размер secured DTCM RAM |
| 15:2 (UR13) | `res` | Резерв |
| 16 (UR13) | D1SBRST | 1 — сброс D1 при входе в Standby |
| 31:17 (UR13) | `res` | Резерв |
| 0 (UR14) | D1STPRST | 1 — сброс D1 при входе в Stop |
| 31:1 (UR14) | `res` | Резерв |
| 15:0 (UR15) | `res` | Резерв |
| 16 (UR15) | FZIWDGSTB | 1 — остановить IWDG в Standby |
| 31:17 (UR15) | `res` | Резерв |
| 0 (UR16) | FZIWDGSTP | 1 — остановить IWDG в Stop |
| 15:1 (UR16) | `res` | Резерв |
| 16 (UR16) | PKP | 1 — private key protection |
| 31:17 (UR16) | `res` | Резерв |
| 0 (UR17) | IOHSLV | 1 — I/O high-speed при низком VDD (глобально) |
| 31:1 (UR17) | `res` | Резерв |

UR18 без битовых define в заголовке — целиком `res`.
