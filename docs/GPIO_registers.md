# GPIO — регистры (STM32H723VGT6)

Справочник по регистрам портов ввода-вывода. Сверено с `Inc/stm32h723xx.h`
(`GPIO_TypeDef`, битовые маски `GPIO_*_Pos`). Порты: A, B, C, D, E, F, G, H, J, K
(порта I в корпусе нет — в заголовке `GPIOI_BASE` отсутствует).

## Базовые адреса

`PERIPH_BASE = 0x40000000`, `D3_AHB1PERIPH_BASE = 0x58020000`
(`PERIPH_BASE + 0x18020000`).

| Порт | База (из заголовка) | Адрес |
|------|---------------------|-------|
| GPIOA | `D3_AHB1PERIPH_BASE + 0x0000` | 0x58020000 |
| GPIOB | `D3_AHB1PERIPH_BASE + 0x0400` | 0x58020400 |
| GPIOC | `D3_AHB1PERIPH_BASE + 0x0800` | 0x58020800 |
| GPIOD | `D3_AHB1PERIPH_BASE + 0x0C00` | 0x58020C00 |
| GPIOE | `D3_AHB1PERIPH_BASE + 0x1000` | 0x58021000 |
| GPIOF | `D3_AHB1PERIPH_BASE + 0x1400` | 0x58021400 |
| GPIOG | `D3_AHB1PERIPH_BASE + 0x1800` | 0x58021800 |
| GPIOH | `D3_AHB1PERIPH_BASE + 0x1C00` | 0x58021C00 |
| GPIOJ | `D3_AHB1PERIPH_BASE + 0x2400` | 0x58022400 |
| GPIOK | `D3_AHB1PERIPH_BASE + 0x2800` | 0x58022800 |

## Смещения регистров (из `GPIO_TypeDef`)

| Смещение | Регистр | Назначение |
|----------|---------|------------|
| 0x00 | MODER | Режим пинов |
| 0x04 | OTYPER | Тип выхода |
| 0x08 | OSPEEDR | Скорость выхода |
| 0x0C | PUPDR | Подтяжки |
| 0x10 | IDR | Входные данные |
| 0x14 | ODR | Выходные данные |
| 0x18 | BSRR | Атомарные set/reset |
| 0x1C | LCKR | Замок конфигурации |
| 0x20 | AFRL | Альт. функция пинов 0–7 |
| 0x24 | AFRH | Альт. функция пинов 8–15 |

> ВАЖНО: регистра BRR в `GPIO_TypeDef` заголовка НЕТ (только 9 регистров выше).
> Сброс пина делается старшей половиной BSRR (`BRy`, биты 16–31). Отдельного
> файла/регистра BRR не существует — не искать его в `stm32h723xx.h`.

## MODER (0x00) — режим пинов

По 2 бита на пин: `MODERn_Pos = 2*n` (`GPIO_MODER_MODERn_Pos`: 0, 2, 4 … 30).

## LCKR (0x1C) — замок конфигурации

`LCKn_Pos = n` (0–15), `LCKK_Pos = 16` (`GPIO_LCKR_LCKK_Pos`).
LCKn=1 выбирает пины для заморозки, LCKK запускает последовательность.

| 2 | LCK2 | 1 — заморозить пин 2 |
| 3 | LCK3 | 1 — заморозить пин 3 |
| 4 | LCK4 | 1 — заморозить пин 4 |
| 5 | LCK5 | 1 — заморозить пин 5 |
| 6 | LCK6 | 1 — заморозить пин 6 |
| 7 | LCK7 | 1 — заморозить пин 7 |
| 8 | LCK8 | 1 — заморозить пин 8 |
| 9 | LCK9 | 1 — заморозить пин 9 |
| 10 | LCK10 | 1 — заморозить пин 10 |
| 11 | LCK11 | 1 — заморозить пин 11 |
| 12 | LCK12 | 1 — заморозить пин 12 |
| 13 | LCK13 | 1 — заморозить пин 13 |
| 14 | LCK14 | 1 — заморозить пин 14 |
| 15 | LCK15 | 1 — заморозить пин 15 |
| 16 | LCKK | Ключ блокировки (участвует в последовательности) |
| 31:17 | `res` | Резерв |

Lock-последовательность (пока LCKK читается как 0):
1. Записать LCKR с LCKK=1 и нужными LCKn=1.
2. Записать LCKR с LCKK=0 и теми же LCKn.
3. Записать LCKR снова с LCKK=1 и теми же LCKn.
4. Дважды прочитать LCKR: замок активен, если LCKK читается как 1.
Снять замок можно только сбросом МК.

## AFRL (0x20) / AFRH (0x24) — альтернативные функции

По 4 бита на пин. AFRL: `AFSELn_Pos = 4*n`, n=0–7 (0, 4, 8 … 28).
AFRH: `AFSELn_Pos = 4*(n-8)`, n=8–15 (0, 4, 8 … 28).

| Биты | Имя | Что делает |
|------|-----|------------|
| 3:0 | AFSEL0 (AFRL) | AF пина 0 (0–15) |
| 7:4 | AFSEL1 (AFRL) | AF пина 1 |
| 11:8 | AFSEL2 (AFRL) | AF пина 2 |
| 15:12 | AFSEL3 (AFRL) | AF пина 3 |
| 19:16 | AFSEL4 (AFRL) | AF пина 4 |
| 23:20 | AFSEL5 (AFRL) | AF пина 5 |
| 27:24 | AFSEL6 (AFRL) | AF пина 6 |
| 31:28 | AFSEL7 (AFRL) | AF пина 7 |
| 3:0 | AFSEL8 (AFRH) | AF пина 8 |
| 7:4 | AFSEL9 (AFRH) | AF пина 9 |
| 11:8 | AFSEL10 (AFRH) | AF пина 10 |
| 15:12 | AFSEL11 (AFRH) | AF пина 11 |
| 19:16 | AFSEL12 (AFRH) | AF пина 12 |
| 23:20 | AFSEL13 (AFRH) | AF пина 13 |
| 27:24 | AFSEL14 (AFRH) | AF пина 14 |
| 31:28 | AFSEL15 (AFRH) | AF пина 15 |

В заголовке есть только позиции/маски (`GPIO_AFRL_AFSELn`, `GPIO_AFRH_AFSELn`),
именованных значений AF нет — их брать из даташита на конкретный корпус.
Общее правило для H7: AF0–AF15, где AF7 = USART1/2/3/6 и SPI1/2/3,
AF4/AF5 — I2C/SPI, AF11 — ETH, AF12 — FMC/SDMMC, AF13 — DCMI и т.д.
Точную таблицу смотреть в даташите STM32H723 (раздел Alternate functions).

## Типовые последовательности (bare-metal)

Выход push-pull:
```
GPIOx->MODER  &= ~(0x3 << (2*n));  GPIOx->MODER  |= (0x1 << (2*n)); // 01 выход
GPIOx->OTYPER &= ~(0x1 << n);                                       // push-pull
GPIOx->OSPEEDR|=  (0x3 << (2*n));                                   // очень высокая
GPIOx->PUPDR  &= ~(0x3 << (2*n));                                   // без подтяжки
```

Альтернативная функция AFm:
```
GPIOx->MODER  = (GPIOx->MODER & ~(0x3 << (2*n))) | (0x2 << (2*n));  // 10 = AF
if (n < 8)  { GPIOx->AFR[0] = (GPIOx->AFR[0] & ~(0xF << (4*n)))     | (m << (4*n)); }
else        { GPIOx->AFR[1] = (GPIOx->AFR[1] & ~(0xF << (4*(n-8)))) | (m << (4*(n-8))); }
```

Аналоговый вход (ADC): `MODER = 11`, `PUPDR = 00`.
