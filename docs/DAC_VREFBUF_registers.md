# DAC1 + VREFBUF — справочник регистров (STM32H723VGT6, CMSIS, русский язык)

Источник позиций и ширины бит: `Inc/stm32h723xx.h` (проверено через `Select-String`, по памяти ничего не писалось).
Структуры: `DAC_TypeDef`, `VREFBUF_TypeDef`.

## Базы и смещения

| Блок | База (из заголовка) | Расчёт |
|---|---|---|
| DAC1 | `DAC1_BASE = D2_APB1PERIPH_BASE + 0x7400` | `0x40000000 + 0x7400 = 0x40007400` |
| VREFBUF | `VREFBUF_BASE = D3_APB1PERIPH_BASE + 0x3C00` | `0x58000000 + 0x3C00 = 0x58003C00` |

`DAC2` в заголовке `stm32h723xx.h` ОТСУТСТВУЕТ (есть только `DAC1`) — второй ЦАП описывается как «каналы 1/2 внутри DAC1». Все `x=2` ниже — второй канал DAC1.

Смещения `DAC_TypeDef` (из заголовка):

| Смещение | Регистр | Смещение | Регистр |
|---|---|---|---|
| 0x00 | CR | 0x28 | DHR8RD (двойной, оба канала) |
| 0x04 | SWTRIGR | 0x2C | DOR1 |
| 0x08 | DHR12R1 | 0x30 | DOR2 |
| 0x0C | DHR12L1 | 0x34 | SR |
| 0x10 | DHR8R1 | 0x38 | CCR |
| 0x14 | DHR12R2 | 0x3C | MCR |
| 0x18 | DHR12L2 | 0x40 | SHSR1 |
| 0x1C | DHR8R2 | 0x44 | SHSR2 |
| 0x20 | DHR12RD (двойной) | 0x48 | SHHR |
| 0x24 | DHR12LD (двойной) | 0x4C | SHRR |

Смещения `VREFBUF_TypeDef`: 0x00 = CSR, 0x04 = CCR.

## DAC CR (0x00) — управление (канал 1 — младшие 16 бит, канал 2 — старшие)

Канал 1:

| Биты | Имя | Что делает |
|---|---|---|
| 0 | EN1 | Включить канал 1 (`Pos=0`) |
| 1 | TEN1 | Включить триггер канала 1 (без него данные из DHR сразу идут в DOR) |
| 5:2 | TSEL1[3:0] | Выбор источника триггера канала 1 (`Pos=2`): TIM-триггеры/EXTI/SWTRIG |
| 7:6 | WAVE1[1:0] | Встроенный генератор (`Pos=6`): 00=выкл, 01=шум (LFSR+`MAMP1`), 10=треугольник (`MAMP1`) |
| 11:8 | MAMP1[3:0] | Амплитуда шума/треугольника (`Pos=8`) |
| 12 | DMAEN1 | Разрешить DMA канала 1 |
| 13 | DMAUDRIE1 | Прерывание по underrun DMA канала 1 |
| 14 | CEN1 | Включить калибровку канала 1 |
| 15 | `res` | Резерв |

Канал 2 (зеркально +16):

| Биты | Имя | Что делает |
|---|---|---|
| 16 | EN2 | Включить канал 2 (`Pos=16`) |
| 17 | TEN2 | Включить триггер канала 2 |
| 21:18 | TSEL2[3:0] | Источник триггера канала 2 (`Pos=18`) |
| 23:22 | WAVE2[1:0] | Генератор канала 2 (`Pos=22`) |
| 27:24 | MAMP2[3:0] | Амплитуда канала 2 (`Pos=24`) |
| 28 | DMAEN2 | DMA канала 2 |
| 29 | DMAUDRIE2 | Прерывание underrun канала 2 |
| 30 | CEN2 | Калибровка канала 2 |
| 31 | `res` | Резерв |

## DAC SWTRIGR (0x04) — программный триггер

| Биты | Имя | Что делает |
|---|---|---|
| 0 | SWTRIG1 | Пиши 1 = программный триггер канала 1 (работает при `TEN1=1, TSEL1=0xx` = software) |
| 1 | SWTRIG2 | То же для канала 2 |
| 31:2 | `res` | Резерв |

## DAC DOR1 (0x2C) / DOR2 (0x30) — выходные регистры (только чтение)

| Биты | Имя | Что делает |
|---|---|---|
| 11:0 | DACCxDOR[11:0] | Текущее значение на выходе канала (`Pos=0`, маска `0xFFF`; обновляется по триггеру из DHR) |
| 31:12 | `res` | Резерв |

## DAC SR (0x34) — статус

| Биты | Имя | Что делает |
|---|---|---|
| 12:0 | `res` | Резерв |
| 13 | DMAUDR1 | Underrun DMA канала 1: новый триггер пришёл раньше, чем DMA отдало данные (пиши 1 для сброса) |
| 14 | CAL_FLAG1 | Статус калибровки канала 1 (смещение откалибровано) |
| 15 | BWST1 | Флаг «занят записью sample-time» канала 1 (sample-and-hold). ВНИМАНИЕ: маска в заголовке `DAC_SR_BWST1_Msk = (0x4001UL << 15)` — нестандартная (покрывает биты 15 и 30); по смыслу бит канала 1 — 15 |
| 28:16 | `res` | Резерв (кроме бита 30, входящего в маску BWST1 по заголовку) |
| 29 | DMAUDR2 | Underrun канала 2 |
| 30 | CAL_FLAG2 | Статус калибровки канала 2 |
| 31 | BWST2 | Флаг записи sample-time канала 2 (`Pos=31`) |

## DAC CCR (0x38) — подстройка смещения

| Биты | Имя | Что делает |
|---|---|---|
| 4:0 | OTRIM1[4:0] | Тримминг смещения канала 1 (`Pos=0`, маска `0x1F`) |
| 15:5 | `res` | Резерв |
| 20:16 | OTRIM2[4:0] | Тримминг канала 2 (`Pos=16`) |
| 31:21 | `res` | Резерв |

ВНИМАНИЕ: полей `STIRx` в `DAC_CCR` этого заголовка НЕТ — есть только `OTRIM1/OTRIM2`. Поле `STIRx` из ТЗ отсутствует, это расхождение зафиксировано.

## VREFBUF CSR (0x00) — управление буфером опорного напряжения

| Биты | Имя | Что делает |
|---|---|---|
| 0 | ENVR | Включить буфер VREFBUF (1 = VREF+ формируется от внутреннего источника) |
| 1 | HIZ | Высокоимпедансный режим пина VREF+ (1 = пин отключён, внешний ИОН) |
| 2 | `res` | Резерв (в заголовке нет бита 2) |
| 3 | VRR | Флаг готовности VREFBUF (1 = выход стабилен, можно запускать ADC/DAC) |
| 6:4 | VRS[2:0] | Шкала напряжения (`Pos=4`, маска `0x7`): `VRS_OUT1=0` (VREF_OUT1 ≈ 2.048 В), `OUT2` (бит 4 ≈ 2.5 В), `OUT3` (бит 5), `OUT4` (биты 5:4 ≈ 1.8 В — точные значения по RM/даташиту) |
| 31:7 | `res` | Резерв |

ВНИМАНИЕ: полей `HRRV/RRV` в `VREFBUF_CSR` этого заголовка НЕТ — есть `ENVR/HIZ/VRR/VRS`. Поля `HRRV/RRV` из ТЗ отсутствуют, это расхождение зафиксировано.

## VREFBUF CCR (0x04) — калибровка

| Биты | Имя | Что делает |
|---|---|---|
| 5:0 | TRIM[5:0] | Код подстройки выхода VREFBUF (`Pos=0`, маска `0x3F`; 0 = заводской центр) |
| 31:6 | `res` | Резерв |

## Алгоритм вывода (bare-metal, CMSIS)

Генерация синуса через TIM-триггер + DMA circular (канал 1):

1. VREFBUF (если нужен внутренний ИОН): `VREFBUF->CSR`: выставь `VRS` (шкала), сбрось `HIZ=0`, `ENVR=1`; дождись `VRR=1`. Иначе оставь `HIZ=1` и подай внешний VREF+.
2. Такты и GPIO: включи `DAC` в `RCC`, настрой аналоговый пин (`MODER=11`); настрой TIM (например TIM6/TIM7): предделитель + `ARR` = частота сэмплов `Fs = Ftim / ((PSC+1) * (ARR+1))`, `MMS`/`TRGO` = update-event.
3. Режим: `DAC1->MCR`: `MODE1=000` (normal). Триггер: `CR`: `TEN1=1`, `TSEL1` = код TRGO твоего таймера, `DMAEN1=1`, `WAVE1=00` (свой синус из таблицы, не LFSR!).
4. DMA: таблица синуса (например 64–256 точек, `uint16_t`, 12 бит) в SRAM; DMA: память→периферия, адрес периферии = `&DAC1->DHR12R1`, размер = half-word, `MINC=1, PINC=0, CIRC=1`, запрос = DAC_CH1. Длина = числу точек.
5. Старт: `DMA enable` → `DAC1->CR |= EN1` → запусти TIM. Дальше каждый TRGO сдвигает очередную точку в `DOR1` без участия CPU.
6. Underrun: если `SR.DMAUDR1=1` — DMA не успевает (шина/приоритет): подними приоритет DMA, уменьши `Fs` или ускорь шину; сбрось флаг записью 1.
7. Останов: стоп TIM → `CR.EN1=0` → стоп DMA. Для двух каналов одновременно — двойной регистр `DHR12RD` + dual-DMA.
8. Калибровка смещения (опционально): `CR.CEN1=1`, дождись `SR.CAL_FLAG1`, подстрой `CCR.OTRIM1`.
