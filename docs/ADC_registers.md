# ADC1 / ADC2 / ADC3 — справочник регистров (STM32H723VGT6, CMSIS, русский язык)

Источник позиций и ширины бит: `Inc/stm32h723xx.h` (проверено через `Select-String`, по памяти ничего не писалось).
Структура `ADC_TypeDef` — смещения из заголовка. Общий блок — `ADC_Common_TypeDef`.

## Базы и смещения

| Блок | База (из заголовка) | Расчёт |
|---|---|---|
| ADC1 | `ADC1_BASE = D2_AHB1PERIPH_BASE + 0x2000` | `0x40020000 + 0x2000 = 0x40022000` |
| ADC2 | `ADC2_BASE = D2_AHB1PERIPH_BASE + 0x2100` | `0x40020000 + 0x2100 = 0x40022100` |

## ISR (0x00) — флаги статуса/прерываний, запись 1 сбрасывает флаг

| Биты | Имя | Что делает |
|---|---|---|
| 0 | ADRDY | АЦП готов после включения (выставляется аппаратно, когда `ADEN=1` завершено) |
| 1 | EOSMP | Конец фазы выборки регулярной группы |
| 2 | EOC | Конец каждого регулярного преобразования (читай `DR`, флаг сбрасывается чтением/записью 1) |
| 3 | EOS | Конец регулярной последовательности (все `SQx` по `L`) |
| 4 | OVR | Переполнение: новые данные пришли до чтения `DR` (поведение зависит от `OVRMOD`) |
| 5 | JEOC | Конец каждого инжективного преобразования (читай `JDRx`) |
| 6 | JEOS | Конец инжективной последовательности |
| 7 | AWD1 | Сработал аналоговый сторож AWD1 (условия — `CFGR`, пороги — `LTR1/HTR1`) |
| 8 | AWD2 | Сработал AWD2 (каналы — `AWD2CR`, пороги — `LTR2/HTR2`) |
| 9 | AWD3 | Сработал AWD3 (каналы — `AWD3CR`, пороги — `LTR3/HTR3`) |
| 10 | JQOVF | Переполнение очереди инжективных контекстов |
| 11 | `res` | Резерв |
| 12 | LDORDY | Готовность внутреннего LDO АЦП |
| 31:13 | `res` | Резерв |

Макросы: `ADC_ISR_ADRDY_Pos=0`, `EOSMP=1`, `EOC=2`, `EOS=3`, `OVR=4`, `JEOC=5`, `JEOS=6`, `AWD1=7`, `AWD2=8`, `AWD3=9`, `JQOVF=10`, `LDORDY=12`.

| 23 | LINCALRDYW2 | Готовность слова 2 |

| 27 | LINCALRDYW6 | Готовность слова 6 |

| 30 | ADCALDIF | Калибровать в дифференциальном режиме (0 = single-ended) |
| 31 | ADCAL | Запуск калибровки (1 = идёт; сбрасывается аппаратно; запускать при `ADEN=0, DEEPPWD=0, ADVREGEN=1`) |

## CFGR (0x0C) — конфигурация

| Биты | Имя | Что делает |
|---|---|---|
| 1:0 | DMNGT[1:0] | Управление данными/DMA регулярной группы (`ADC_CFGR_DMNGT_Pos=0`): 00 = данные в `DR`, без DMA; 01 = DMA one-shot; 10 = DFSDM; 11 = DMA circular. ВНИМАНИЕ: отдельных `DMAEN/DMACFG` в этом заголовке НЕТ — их заменяет `DMNGT` |
| 4:2 | RES[2:0] | Разрешение: 000=16 бит, 001=14, 010=12, 011=10, 100=8 бит (`ADC_CFGR_RES_Pos=2`) |
| 9:5 | EXTSEL[4:0] | Выбор триггера регулярной группы (`Pos=5`) |
| 11:10 | EXTEN[1:0] | Полярность внешнего триггера регулярной группы: 00=выкл, 01=front, 10=fall, 11=оба (`Pos=10`) |
| 12 | OVRMOD | Режим переполнения: 0 = `DR` сохраняется, флаг OVR; 1 = перезапись новыми данными |
| 13 | CONT | 0 = одиночный проход последовательности; 1 = непрерывный режим (рестарт после EOS) |
| 14 | AUTDLY | Автозадержка: следующее преобразование ждёт чтения `DR`/`JDR` (низкая частота, без OVR) |
| 15 | `res` | Резерв |
| 16 | DISCEN | Дискретный режим регулярной группы (по `DISCNUM` каналов на триггер) |
| 19:17 | DISCNUM[2:0] | Длина подгруппы дискретного режима − 1 (`Pos=17`) |
| 20 | JDISCEN | Дискретный режим инжективной группы |
| 21 | JQM | Режим очереди JSQR: 0 = очередь при `JAUTO`/триггерах, 1 = JSQR управляется `JADSTART` |
| 22 | AWD1SGL | AWD1: 1 = один канал (`AWD1CH`), 0 = все каналы |
| 23 | AWD1EN | AWD1 на регулярные каналы |
| 24 | JAWD1EN | AWD1 на инжективные каналы |
| 25 | JAUTO | Авто-преобразование инжективной группы после регулярной |
| 30:26 | AWD1CH[4:0] | Номер канала для AWD1 в одиночном режиме (`Pos=26`) |
| 31 | JQDIS | 1 = запретить очередь инжективных контекстов |

В заголовке НЕТ бита `AUTOFF` (есть только `AUTDLY`) — поле `AUTOFF` из ТЗ отсутствует, это расхождение зафиксировано.

## SMPR1 (0x14) / SMPR2 (0x18) — время выборки по каналам

Каждый канал — 3 бита `SMPx[2:0]`. `SMPR1`: каналы 0–9 (`SMP0_Pos=0, SMP1=3, … SMP9=27`).
`SMPR2`: каналы 10–19 (`SMP10_Pos=0 … SMP19=27`). Старшие биты 31:30 в SMPR1/SMPR2 — `res`.
Код выборки 0–7 = от короткой к длинной выборке (циклы ADC-CLK смотри в RM; заголовок хранит только позиции).
Канал сначала должен быть разрешён в `PCSEL`, иначе время игнорируется.

## PCSEL (0x1C) — предвыбор каналов (важно!)

| Биты | Имя | Что делает |
|---|---|---|
| 19:0 | PCSEL[19:0] | 1 = канал `n` предварительно выбран (подключён к АЦП). Без установки бита преобразование канала из `SQR/JSQR` не пойдёт (`ADC_PCSEL_PCSEL_Pos=0`, маска `0xFFFFF`) |
| 31:20 | `res` | Резерв |

## SQR1–SQR4 (0x30–0x3C) — регулярная группа

SQR1:

| Биты | Имя | Что делает |
|---|---|---|
| 3:0 | L[3:0] | Длина последовательности − 1: 0 = 1 преобразование … 15 = 16 (`Pos=0`) |
| 5:4 | `res` | Резерв |
| 10:6 | SQ1[4:0] | 1-й канал (`Pos=6`) |
| 16:11 | `res`+SQ2 | SQ2[4:0] в битах 16:12 (`Pos=12`), бит 11 — `res` |
| 22:18 | SQ3[4:0] | 3-й канал (`Pos=18`), биты 17 — `res` |
| 28:24 | SQ4[4:0] | 4-й канал (`Pos=24`), бит 23 — `res` |
| 31:29 | `res` | Резерв |

SQR2: SQ5 (`7:0`→биты 4:0, `Pos=0`), SQ6 (`Pos=6`), SQ7 (`Pos=12`), SQ8 (`Pos=18`), SQ9 (`Pos=24`).
SQR3: SQ10–SQ14 аналогично. SQR4: SQ15 (`Pos=0`), SQ16 (`Pos=6`), биты 31:11 — `res`.
Каждый `SQx` — 5 бит, значения 0–19 = номер канала.

| 1:0 | JL[1:0] | Длина инжективной последовательности − 1 (`Pos=0`) |

## Пороги AWD: LTR1/HTR1 (0x20/0x24), LTR2/HTR2, LTR3/HTR3

В заголовке пороги названы `ADC_LTR_LT` / `ADC_HTR_HT`:

| Биты | Имя | Что делает |
|---|---|---|
| 25:0 | LT[25:0] / HT[25:0] | Нижний/верхний порог AWD1/2/3 (`Pos=0`, маска `0x3FFFFFF`). Сравниваются с данными с учётом `RES/OVSS/LSHIFT` |
| 31:26 | `res` | Резерв |

Привязка (имена полей структуры!): 0x20 = `LTR1_TR1` (AWD1 low), 0x24 = `HTR1_TR2` (AWD1 high),
0xB0 = `LTR2_DIFSEL` (AWD2 low; у ADC3 это DIFSEL), 0xB4 = `HTR2_CALFACT` (AWD2 high; у ADC3 это CALFACT),
0xB8 = LTR3 (AWD3 low, только ADC1/2), 0xBC = HTR3 (AWD3 high, только ADC1/2), 0x28 = TR3 (только ADC3).

## Общий блок: CSR (+0x300) / CCR (+0x308) / CDR (+0x30C) / CDR2 (+0x310)

CSR — те же флаги, что ISR, но отдельно master/slave (младшие 16 бит — master ADC1/ADC3, старшие — slave ADC2):
`ADRDY_MST=0/EOSMP_MST=1/EOC_MST=2/EOS_MST=3/OVR_MST=4/JEOC_MST=5/JEOS_MST=6/AWD1_MST=7/AWD2_MST=8/AWD3_MST=9/JQOVF_MST=10`,
`ADRDY_SLV=16 … JQOVF_SLV=26`. Остальные биты — `res`.

CCR:

| Биты | Имя | Что делает |
|---|---|---|
| 4:0 | DUAL[4:0] | Dual-режим ADC1+ADC2 (`Pos=0`): 0 = независимые; комбинации injected/regular/interleaved — по RM |
| 7:5 | `res` | Резерв |
| 11:8 | DELAY[3:0] | Задержка между фазами выборки в interleaved/dual (`Pos=8`) |
| 13:12 | `res` | Резерв |
| 15:14 | DAMDF[1:0] | Формат данных dual-режима (`Pos=14`) |
| 17:16 | CKMODE[1:0] | Тактирование АЦП (`Pos=16`): 00 = HCLK/1–2 (синхр.), 01 = HCLK/1 (div1), 10 = HCLK/2 (div2), 11 = асинхронный kernel-clock |
| 21:18 | PRESC[3:0] | Предделитель async-частоты АЦП (`Pos=18`) |
| 22 | VREFEN | Включить внутренний источник VREFINT (нужен для канала VREFINT) |
| 23 | TSEN | Включить температурный сенсор (нужен для канала темп-сенсора) |
| 24 | VBATEN | Включить канал VBAT |
| 31:25 | `res` | Резерв |

ВНИМАНИЕ: полей `MDMA/DMACFG` в `ADC_CCR` этого заголовка НЕТ — DMA регулярной группы настраивается через `CFGR.DMNGT`, dual-DMA — через `DUAL/DAMDF` + `CDR/CDR2`.

CDR: `RDATA_MST[15:0]` (`Pos=0`) + `RDATA_SLV[15:0]` (`Pos=16`) — пара для dual-режима.
CDR2: `RDATA_ALT[31:0]` — 32-битный вариант для dual.

## Каналы и внутренние источники (кратко)

- Внешние каналы 0–19 (точное соответствие пинам — по даташиту корпуса; `PCSEL[n]` обязателен!).
- Внутренние: температурный сенсор (требует `CCR.TSEN=1` + время выборки побольше), VREFINT (`CCR.VREFEN=1`), VBAT (`CCR.VBATEN=1`).
- Дифференциальные пары включаются через `DIFSEL` (только ADC1/2 в этом заголовке).

## Алгоритм работы (bare-metal, CMSIS)

1. Тактирование и GPIO: включи такты ADC (`RCC`), настрой аналоговые пины (`GPIOx.MODER=11`, `ASCR` при наличии).
2. Выход из deep power-down: `ADCx->CR &= ~ADC_CR_DEEPPWD_Msk;` затем `ADCx->CR |= ADC_CR_ADVREGEN_Msk;` — подожди стабилизацию регулятора (задержка по RM, флаг `ISR.LDORDY`).
3. Калибровка: убедись `ADEN=0`; выбери `ADCALDIF` (0 = single-ended); опционально `ADCALLIN` для линейности; `CR |= ADCAL; while(CR & ADCAL){}`; факторы появятся в `CALFACT/CALFACT2`.
4. Включение: `CR |= ADEN; while(!(ISR & ADRDY)){}`. Общий блок: настрой `CCR` (`CKMODE/PRESC`, при нужде `TSEN/VREFEN/VBATEN`, `DUAL` для пары ADC1/2) ДО старта.
5. Настройка каналов: `PCSEL` (обязательно!), `SMPR1/2` (внутренним каналам — длинные выборки), `CFGR.RES/EXTSEL/EXTEN/CONT/AUTDLY/OVRMOD/DMNGT`, `SQRx/JSQR`, пороги `LTR/HTR` + `AWDxCR` при нужде, `IER` при прерываниях.
6. Старт: `CR |= ADSTART` (регулярные) / `JADSTART` (инжективные). Опрос/прерывание: `EOC` — один канал (`DR`), `EOS` — вся очередь; `JEOC/JEOS` + `JDRx` — инжективные.
7. Режимы: одиночный (`CONT=0`, стоп после `EOS`); непрерывный (`CONT=1`); дискретный (`DISCEN=1` + `DISCNUM`, каждый триггер — подгруппа); программный триггер — `EXTEN=00` + `ADSTART`; аппаратный — `EXTSEL+EXTEN`.
8. DMA: `CFGR.DMNGT=01` — DMA one-shot (стоп по `EOS`), `=11` — circular (поток без останова); приёмник — `DR` (single) или `CDR/CDR2` (dual). `OVRMOD` выбирает: сохранять старое или перезаписывать.
9. Выключение: `ADSTP` → дождись `ADSTART=0`; `ADDIS` → дождись `ADEN=0`; при уходе в сон — `DEEPPWD=1`.
