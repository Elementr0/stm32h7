# TIM — справочник регистров (STM32H723VGT6, CMSIS, без HAL)

Общие таймеры **TIM2/3/4/5**: TIM2 и TIM5 — 32-битные, TIM3 и TIM4 — 16-битные; по 4 канала захвата/сравнения.
Позиции и ширина бит проверены по `Inc/stm32h723xx.h` (`TIM_CR1/CR2/SMCR/DIER/SR/EGR/CCMR/CCER/BDTR/DCR_*_Pos/Msk`, `TIM_CNT/UIFCPY`, `LPTIM_*`). Структура: `TIM_TypeDef` (смещения ниже), `LPTIM_TypeDef`.

Базовые адреса (из заголовка; `PERIPH_BASE = 0x40000000`):

| Таймер | База | Разрядность | Каналы |
|---|---|---|---|
| TIM2 | `0x40000000` | 32 бита | 4 |
| TIM3 | `0x40000400` | 16 бит | 4 |
| TIM4 | `0x40000800` | 16 бит | 4 |
| TIM5 | `0x40000C00` | 32 бита | 4 |
| TIM6 | `0x40001000` | 16 бит, базовый | нет |
| TIM7 | `0x40001400` | 16 бит, базовый | нет |
| TIM1 | `0x40010000` | 16 бит, продвинутый | 6 |
| TIM8 | `0x40010400` | 16 бит, продвинутый | 6 |
| LPTIM1 | `0x40002400` | 16 бит | 1 (сравнение) |

Смещения `TIM_TypeDef`: `CR1 +0x00`, `CR2 +0x04`, `SMCR +0x08`, `DIER +0x0C`, `SR +0x10`, `EGR +0x14`, `CCMR1 +0x18`, `CCMR2 +0x1C`, `CCER +0x20`, `CNT +0x24`, `PSC +0x28`, `ARR +0x2C`, `RCR +0x30`, `CCR1 +0x34`, `CCR2 +0x38`, `CCR3 +0x3C`, `CCR4 +0x40`, `BDTR +0x44`, `DCR +0x48`, `DMAR +0x4C`, `CCMR3 +0x54`, `CCR5 +0x58`, `CCR6 +0x5C`, `AF1 +0x60`, `AF2 +0x64`, `TISEL +0x68`.

## 1. CR1 — основной контроль

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `CEN` | 1 — счёт включён; 0 — остановлен |
| 1 | `UDIS` | 1 — запретить событие обновления (тень `ARR/PSC/CCRx` не перезагружается, `UIF` не ставится) |
| 2 | `URS` | 1 — только переполнение/опустошение ставит `UIF`; программный `UG` — нет |
| 3 | `OPM` | 1 — однопроходный режим: счёт останавливается после следующего события обновления |
| 4 | `DIR` | 0 — счёт вверх, 1 — счёт вниз (плюс режимы `CMS` ниже) |
| 6:5 | `CMS[1:0]` | Режим выравнивания: `00` — по фронту (up/down по `DIR`), `01/10/11` — центральные режимы 1/2/3 (счёт вверх+вниз, флаги сравнения ставятся на разных фазах) |
| 7 | `ARPE` | 1 — `ARR` с предзагрузкой (теневое обновление по событию обновления); 0 — `ARR` пишется сразу |
| 9:8 | `CKD[1:0]` | Делитель тактов dead-time/фильтра: `00` — `t_DTS = t_CK_INT`, `01` — ×2, `10` — ×4 |
| 10 | `res` | Зарезервировано |
| 11 | `UIFREMAP` | 1 — бит `UIF` копируется в бит 31 `CNT` (`UIFCPY`, только чтение) |
| 31:12 | `res` | Зарезервировано |

Позиции проверены: `CEN=0`, `UDIS=1`, `URS=2`, `OPM=3`, `DIR=4`, `CMS=5` (маска `0x3`), `ARPE=7`, `CKD=8` (маска `0x3`), `UIFREMAP=11`.

## 2. CR2 — выход мастера (MMS!)

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `CCPC` | 1 — предзагрузка `CCxE/CCxNE/OCxM` обновляется по событию COM (`COMG`) |
| 1 | `res` | Зарезервировано |
| 2 | `CCUS` | Выбор источника обновления предзагруженных бит захвата/сравнения (при `CCPC=1`) |
| 3 | `CCDS` | 1 — запрос DMA на `CCx` идёт по событию `CCx`, 0 — по событию обновления |
| 6:4 | `MMS[2:0]` | **Выбор выхода TRGO мастера:** `000` — сброс (`UG`), `001` — разрешение (`CEN`), `010` — обновление, `011` — импульс сравнения, `100` — `OC1REF`, `101` — `OC2REF`, `110` — `OC3REF`, `111` — `OC4REF` |
| 7 | `TI1S` | 1 — вход `TI1` — XOR трёх входов (для датчиков Холла) |
| 15:8 | `OISx/OISxN` | Состояния покоя выходов в простое: 8: `OIS1`, 9: `OIS1N`, 10: `OIS2`, 11: `OIS2N`, 12: `OIS3`, 13: `OIS3N`, 14: `OIS4` (есть только у продвинутых; на общих — `res`/не используются) |
| 19:15 | `res` | Зарезервировано (15: `OIS4`, 16: `OIS5`, 18: `OIS6` — только продвинутые; на TIM2–5 — `res`) |
| 23:20 | `MMS2[3:0]` | Второй выход мастера TRGO2 (только продвинутые; на TIM2–5 — `res`) |
| 31:24 | `res` | Зарезервировано |

Позиции проверены: `CCPC=0`, `CCUS=2`, `CCDS=3`, `MMS=4` (маска `0x7`), `TI1S=7`, `MMS2=20` (маска `0xF`).

## 3. SMCR — подчинённый режим

| Биты | Имя | Что делает |
|---|---|---|
| 2:0 + 16 | `SMS[3:0]` | Режим подчинённости: `0000` — выключен (таймер — мастер по внутр. такту); `0001–0011` — кодировщик 1/2/3; `0100` — сброс по фронту триггера; `0101` — стробируемый (счёт пока триггер высок); `0110` — триггерный (старт по фронту); `0111` — внешний такт 1; `1000` — комбинированный сброс+триггер. Старший бит — бит 16 (`SMS_3`, маска `0x10007` — проверено) |
| 3 | `res` | Зарезервировано |
| 6:4 + 21:20 | `TS[4:0]` | Выбор триггера: `00000` — `ITR0` … младшие — внутренние триггеры других таймеров, `00100` — фронт `TI1` (`TI1F_ED`), `00101` — `TI1FP1`, `00110` — `TI2FP2`, `00111` — вход `ETRF`; старшие биты — биты 21:20 (маска `0x30007` — проверено) |
| 7 | `MSM` | 1 — режим master/slave: событие триггера задерживается, чтобы текущий мастер и этот таймер стартовали синхронно |
| 11:8 | `ETF[3:0]` | Фильтр входа `ETR` (глубина/частота выборок; `0000` — без фильтра) |
| 13:12 | `ETPS[1:0]` | Предделитель `ETR`: `00` — /1, `01` — /2, `10` — /4, `11` — /8 |
| 14 | `ECE` | 1 — внешний такт 2: счёт по фронтам `ETR` |
| 15 | `ETP` | Полярность `ETR`: 0 — неинвертирован, 1 — инвертирован |
| 31:17 | `res` (кроме 21:20 — `TS[4:3]`, см. выше) | Зарезервировано |

Позиции проверены: `SMS=0`, `TS=4`, `MSM=7`, `ETF=8` (маска `0xF`), `ETPS=12` (маска `0x3`), `ECE=14`, `ETP=15`. Отдельного бита `SMS_PRELOAD` в заголовке H723 **нет** (в отличие от новых серий) — это расхождение с ожиданиями, не использовать.

## 4. DIER / SR / EGR — прерывания, флаги, генерация

`DIER` — разрешения (чтение/запись), `SR` — флаги (сброс записью `0`! запись `1` игнорируется), `EGR` — программная генерация событий (только запись, бит сам сбрасывается).

| Бит | DIER | SR (сброс 0) | EGR (запись 1) |
|---|---|---|---|
| 0 | `UIE` — прерывание обновления | `UIF` — событие обновления | `UG` — сгенерировать обновление (перезагрузить тень `ARR/PSC`, сбросить счётчик по `DIR/CMS`) |
| 1 | `CC1IE` | `CC1IF` (+ `CC1OF` — бит 9: overcapture) | `CC1G` |
| 2 | `CC2IE` | `CC2IF` (+ `CC2OF` — бит 10) | `CC2G` |
| 3 | `CC3IE` | `CC3IF` (+ `CC3OF` — бит 11) | `CC3G` |
| 4 | `CC4IE` | `CC4IF` (+ `CC4OF` — бит 12) | `CC4G` |
| 5 | `COMIE` — прерывание COM (только продвинутые) | `COMIF` (+ `SBIF` — бит 13: switch break; `CC5IF` — 16, `CC6IF` — 17 — только продвинутые) | `COMG` |
| 6 | `TIE` — прерывание триггера | `TIF` | `TG` |
| 7 | `BIE` — прерывание break (только продвинутые) | `BIF` (+ `B2IF` — бит 8 — только продвинутые) | `BG` (+ `B2G` — бит 8) |
| 8 | `UDE` — DMA по обновлению | (см. `B2IF` выше) | — |
| 9–12 | `CCxDE` — DMA по захвату/сравнению 1–4 | `CCxOF` — флаги overcapture (9–12) | — |
| 13 | `COMDE` — DMA по COM | `SBIF` | — |
| 14 | `TDE` — DMA по триггеру | — | — |

Все позиции проверены (`DIER: UIE=0, CCxIE=1–4, COMIE=5, TIE=6, BIE=7, UDE=8, CCxDE=9–12, COMDE=13, TDE=14`; `SR` и `EGR` — аналогично). На TIM2–5 биты break/COM (`BIE/BIF/BG/COMIE/COMIF/COMG`, `CC5IF/CC6IF`, `B2IF/B2G`) физически не используются — считать `res`.

## 5. CCMR1 / CCMR2 — захват vs сравнение

Регистр двойного назначения: биты трактуются по-разному при `CCxS = 00` (выход/сравнение) и `CCxS ≠ 00` (вход/захват). Ниже для каналов 1–2 (`CCMR1`); `CCMR2` — то же для каналов 3–4 (позиции совпадают: `CC3S=0`, `OC3M=4` и т.д. — проверено).

Режим выхода (`CC1S = 00`), канал 1 (младшая половина):

| Биты | Имя | Что делает |
|---|---|---|
| 1:0 | `CC1S[1:0]` | `00` — канал как выход (сравнение); иначе — вход (см. ниже) |
| 2 | `OC1FE` | Быстрое сравнение (форсированный отклик на триггер) |
| 3 | `OC1PE` | 1 — предзагрузка `CCR1` (теневое обновление по событию обновления); 0 — немедленная запись |
| 6:4 (+16!) | `OC1M[3:0]` | Режим выхода: `000` — заморожен, `001` — высокий при совпадении, `010` — низкий при совпадении, `011` — переключение, `100` — форсированно низко, `101` — форсированно высоко, `110` — ШИМ 1, `111` — ШИМ 2, `1111`? — комбинированные/асимметричные режимы используют бит 16 (`OC1M_3`, маска `0x1007` — проверено): `OC1M[3]` расширяет набор (ретр/комбинир. ШИМ — только продвинутые) |
| 7 | `OC1CE` | 1 — `OC1REF` сбрасывается входом `ETRF` (чистый сброс выхода) |
| 15:8 | канал 2 | Зеркально: `CC2S` (8), `OC2FE` (10), `OC2PE` (11), `OC2M` (12 + бит `OC2M_3`), `OC2CE` (15) |

Режим входа (`CCxS ≠ 00`), канал 1:

| Биты | Имя | Что делает |
|---|---|---|
| 1:0 | `CC1S[1:0]` | Выбор входа: `01` — свой вход `TI1`, `10` — чужой `TI2`, `11` — `TRC` (внутренний триггер) |
| 3:2 | `IC1PSC[1:0]` | Предделитель захвата: `00` — каждое событие, `01` — /2, `10` — /4, `11` — /8 |
| 7:4 | `IC1F[3:0]` | Фильтр входа (глубина/частота выборок; `0000` — без фильтра) |

Позиции проверены: `CC1S=0`, `OC1FE=2`/`IC1PSC=2`, `OC1PE=3`, `OC1M/IC1F=4`, `OC1CE=7`; канал 2: `CC2S=8`, `OC2FE/IC2PSC=10`, `OC2PE=11`, `OC2M/IC2F=12`, `OC2CE=15`.

## 6. CCER — включение и полярность каналов

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `CC1E` | 1 — выход/вход канала 1 включён |
| 1 | `CC1P` | Полярность канала 1: выход — активный уровень; вход — фронт (0 — растущий, 1 — падающий) |
| 3:2 | `CC1NP/CC1NE` | У продвинутых: полярность/включение комплементарного выхода `CC1N`. На TIM2–5: бит 2 (`CC1NE`) — `res`, бит 3 (`CC1NP`) — полярность при захвате обоих фронтов |
| 6:4 | `CC2E/CC2P/CC2NE/CC2NP` | То же для канала 2 (4: `CC2E`, 5: `CC2P`, 6: `CC2NE`-res на общих, 7: `CC2NP`) |
| 10:8 | `CC3E/CC3P/CC3NE/CC3NP` | Канал 3 (8/9/10/11) |
| 12–15 | `CC4E/CC4P/CC4NP` | Канал 4: 12: `CC4E`, 13: `CC4P`, 15: `CC4NP` (бита `CC4NE` нет — проверено, бит 14 — `res`) |
| 16–21 | `CC5E/CC5P/CC6E/CC6P` | Каналы 5–6 — только продвинутые; на TIM2–5 — `res` |

Позиции проверены (`CC1E=0`, `CC1P=1`, `CC1NE=2`, `CC1NP=3`, `CC2E=4` … `CC4P=13`, `CC4NP=15`).

## 7. CNT / PSC / ARR / CCRx

| Регистр | Биты | Что делает |
|---|---|---|
| `CNT` | 30:0 (`TIM2/5`) / 15:0 (`TIM3/4`), бит 31 — `UIFCPY` | Текущий счётчик. Бит 31 (`UIFCPY_Pos=31`) — копия `UIF` при `CR1.UIFREMAP=1` (только чтение) |
| `PSC` | 15:0 (`PSC[15:0]`, `Pos=0`) | Предделитель: частота счёта `f_CK_CNT = f_CK_PSC / (PSC+1)`. Теневой, обновляется по событию обновления |
| `ARR` | 31:0 (`TIM2/5`) / 15:0 (`TIM3/4`) | Автоперезагрузка (период). При `ARPE=1` — теневая |
| `CCR1–CCR4` | 31:0 (`TIM2/5`) / 15:0 (`TIM3/4`) | Захват/сравнение. В ШИМ — порог скважности; в захвате — сюда фиксируется `CNT` |
| `RCR` | — | Счётчик повторов — только продвинутые (см. §9); на TIM2–5 `res` |

## 8. DCR / DMAR — пакетный DMA (burst)

| Биты | Имя | Что делает |
|---|---|---|
| `DCR` 4:0 | `DBA[4:0]` | Базовый адрес burst: смещение первого регистра от `CR1` (`00000` = `CR1`, `00001` = `CR2`, …) |
| `DCR` 12:8 | `DBL[4:0]` | Длина burst: число передач минус 1 (`00000` — 1 передача … до 18) |
| `DCR` 31:13 | `res` | Зарезервировано (бит 13+ — `res`; `DBL_Pos=8`, маска `0x1F` — проверено) |
| `DMAR` 31:0 | `DMAB` | Данные burst: чтение/запись сюда запускает серию обращений, заданную `DBA/DBL` |

## 9. Чем отличаются продвинутые TIM1/8

- Комплементарные выходы `CCxN` + биты `CCxNE/CCxNP` в `CCER`, каналы 5–6 (`CCR5/CCR6`, `CCMR3`).
- `RCR` (+0x30): счётчик повторов — событие обновления только после `RCR+1` переполнений (удобно для управления двигателями/ШИМ с низкой частотой обновления).
- `BDTR` (+0x44) — break и dead-time:

| Биты | Имя | Что делает |
|---|---|---|
| 7:0 | `DTG[7:0]` | Dead-time между `CCx` и `CCxN` (кодировка нелинейная: младшие диапазоны — шаг `t_DTS`, старшие — /2, /8, /16 — см. RM) |
| 9:8 | `LOCK[1:0]` | Уровень защиты от записи: `00` — нет, `01/10/11` — нарастающие запреты (до `CCER/BDTR`) |
| 10 | `OSSI` | Состояние выходов в простое (idle) при `MOE=0` |
| 11 | `OSSR` | Состояние выходов в run при `MOE=0` (аварийный останов) |
| 12 | `BKE` | 1 — вход break включён |
| 13 | `BKP` | Полярность break |
| 14 | `AOE` | 1 — `MOE` сам восстанавливается по событию обновления после break |
| 15 | `MOE` | **Главный выходной каскад: 1 — выходы работают; после break сбрасывается в 0 и глушит всё** |
| 19:16 | `BKF[3:0]` | Фильтр входа break |
| 25:24 | `BK2E/BK2P` … `BK2F[3:0]` (20) | Второй break: `BK2E=24`, `BK2P=25`, фильтр `BK2F=20` (4 бита) |
| 27:26 | `BKDSRM/BK2DSRM` | Сброс режима break (disarm): `BKDSRM=26`, `BK2DSRM=27` |
| 29:28 | `BKBID/BK2BID` | Двунаправленный режим break: `BKBID=28`, `BK2BID=29` |
| 31:30 | `res` | Зарезервировано |

Позиции проверены (`DTG=0`, `LOCK=8`, `OSSI=10`, `OSSR=11`, `BKE=12`, `BKP=13`, `AOE=14`, `MOE=15`, `BKF=16`, `BK2F=20`, `BK2E=24`, `BK2P=25`, `BKDSRM=26`, `BK2DSRM=27`, `BKBID=28`, `BK2BID=29`).

## 10. Базовые TIM6/7

Только база времени, без каналов/CCER/CCMR/BDTR: `CR1 / CR2 (только MMS) / DIER (UIE+UDE) / SR (UIF) / EGR (UG) / CNT / PSC / ARR`. Используются как мастер-тики (прерывание/DAC/RCC-триггеры через `MMS`).

## 11. LPTIM — кратко (LPTIM1/2/3/4/5)

16-битный, работает от медленных/внешних тактов в low-power. Структура `LPTIM_TypeDef`: `ISR +0x00`, `ICR +0x04`, `IER +0x08`, `CFGR +0x0C`, `CR +0x10`, `CMP +0x14`, `ARR +0x18`, `CNT +0x1C`, `CFGR2 +0x24`.

Флаги `ISR/IER/ICR` (биты 6:0, позиции проверены): 0 — `CMPM` (совпадение), 1 — `ARRM` (совпадение авто-перезагрузки), 2 — `EXTTRIG` (внешний триггер), 3 — `CMPOK` (запись `CMP` принята), 4 — `ARROK` (запись `ARR` принята), 5 — `UP` (счёт вверх), 6 — `DOWN` (счёт вниз). В `IER` те же с суффиксом `IE`, в `ICR` — с суффиксом `CF` (сброс записью 1).

`CR`: 0 — `ENABLE`, 1 — `SNGSTRT` (однократный старт), 2 — `CNTSTRT` (непрерывный старт), 3 — `COUNTRST` (сброс счётчика), 4 — `RSTARE` (сброс после чтения). `CNT/CMP/ARR` — 16 бит (`0xFFFF`).

`CFGR`:

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `CKSEL` | 0 — внутренний такт, 1 — внешний (`ULPTIM`) |
| 2:1 | `CKPOL[1:0]` | Полярность внешнего такта: `00` — фронт, `01/10/11` — см. RM |
| 4:3 | `CKFLT[1:0]` | Фильтр внешнего такта |
| 7:6 | `TRGFLT[1:0]` | Фильтр триггера |
| 11:9 | `PRESC[2:0]` | Предделитель: 2^N, N = 0…7 |
| 15:13 | `TRIGSEL[2:0]` | Выбор источника триггера |
| 17:16 | `TRIGEN[1:0]` | Разрешение триггера: `00` — программно, `01/10/11` — фронт/спад/оба |
| 19 | `TIMOUT` | 1 — таймаут (триггер сбрасывает, отсутствие — ставит `ARRM`) |
| 20 | `WAVE` | 1 — генерация меандра на выходе (переключение при `CMPM`) |
| 21 | `WAVPOL` | Полярность меандра |
| 22 | `PRELOAD` | 1 — `CMP/ARR` с предзагрузкой |
| 23 | `COUNTMODE` | 1 — счёт от внешнего входа (а не внутр. такта) |
| 24 | `ENC` | 1 — режим энкодера |
| 31:25 | `res` | Зарезервировано |

`CFGR2`: `IN1SEL[1:0]` (биты 1:0), `IN2SEL[1:0]` (биты 5:4) — выбор входов (позиции `0` и `4` — проверены).

## 12. Формулы: частота и ШИМ

- Такт счёта: `f_CNT = f_TIM / (PSC + 1)`, где `f_TIM` — частота шины таймера (с учётом удвоения APB, если предделитель APB ≠ 1).
- Частота обновления (период): `f_UPD = f_CNT / (ARR + 1)` (счёт вверх, `CMS=00`).
- Период: `T = (PSC + 1) * (ARR + 1) / f_TIM`.
- ШИМ (режим 1, счёт вверх): выход высок, пока `CNT < CCRx` → скважность `D = CCRx / (ARR + 1)`, частота ШИМ = `f_UPD`.
- ШИМ режим 2 — инверсия режима 1. Полярность — бит `CCxP` в `CCER`.
- Захват входа: по фронту `CNT` копируется в `CCRx`; частота сигнала = `f_CNT / delta_CCR` между соседними захватами (с учётом `ICxPSC`).
- Пример: `f_TIM = 100 МГц`, хотим 1 кГц ШИМ с разрешением 1000: `PSC = 99` → `f_CNT = 1 МГц`; `ARR = 999` → `f_UPD = 1 кГц`; `CCRx = 250` → 25 %.
