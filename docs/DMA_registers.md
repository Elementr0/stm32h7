# DMA — справочник регистров (STM32H723VGT6, CMSIS, без HAL)

Контроллеры: **DMA1 / DMA2** (по 8 потоков-stream), **BDMA** (8 каналов), **MDMA** (16 каналов), мультиплексор **DMAMUX1** (+ генераторы запроса).
Без настройки DMAMUX1 поток DMA1/DMA2 не стартует: запрос от периферии выбирается полем `DMAREQ_ID`.

Позиции и ширина бит проверены по `Inc/stm32h723xx.h` (`DMA_SxCR_*_Pos/Msk`, `DMA_LISR/HISR_*`, `BDMA_*`, `DMAMUX_*`, `MDMA_*`). Имена структур: `DMA_TypeDef`, `DMA_Stream_TypeDef`, `BDMA_TypeDef`, `BDMA_Channel_TypeDef`, `DMAMUX_Channel_TypeDef`, `MDMA_Channel_TypeDef`.

Базовые адреса (из заголовка; `PERIPH_BASE = 0x40000000`):

| Блок | База |
|---|---|
| DMA1 | `0x40020000` (`D2_AHB1PERIPH_BASE + 0x0000`) |
| DMA2 | `0x40020400` (`D2_AHB1PERIPH_BASE + 0x0400`) |
| DMAMUX1 | `0x40020800` (`D2_AHB1PERIPH_BASE + 0x0800`) |
| MDMA | `0x52000000` (`D1_AHB1PERIPH_BASE + 0x0000`), каналы: `+0x40 + n*0x40`, n = 0…15 |
| BDMA | `0x58025400` (`D3_AHB1PERIPH_BASE + 0x5400`), каналы: `+0x08 + n*0x14`, n = 0…7 |

Смещения DMA1/DMA2: `LISR +0x00`, `HISR +0x04`, `LIFCR +0x08`, `HIFCR +0x0C`; потоки: `Stream_n +0x10 + n*0x18` (внутри потока: `CR +0x00`, `NDTR +0x04`, `PAR +0x08`, `M0AR +0x0C`, `M1AR +0x10`, `FCR +0x14`).

## 1. DMA1/DMA2 — флаги: LISR / HISR

`LISR` — потоки 0…3, `HISR` — потоки 4…7. Раскладка одинаковая, ниже индексы для LISR (для HISR прибавить 4 к номеру потока).
Каждый поток занимает 6 бит: `FEIF`, 1 резервный бит, `DMEIF`, `TEIF`, `HTIF`, `TCIF`. Между группами — резервные биты.

| Биты | Имя | Что делает |
|---|---|---|
| 5:0 | TCIF0/HTIF0/TEIF0/DMEIF0/FEIF0 (поток 0) | 5: `TCIF0` — передача завершена; 4: `HTIF0` — половина передачи; 3: `TEIF0` — ошибка передачи; 2: `DMEIF0` — ошибка direct mode; 0: `FEIF0` — ошибка FIFO; бит 1 — `res` |
| 11:6 | …IF1 (поток 1) | То же для потока 1: 11: `TCIF1`, 10: `HTIF1`, 9: `TEIF1`, 8: `DMEIF1`, 6: `FEIF1`; бит 7 — `res` |
| 15:12 | `res` | Зарезервировано |
| 21:16 | …IF2 (поток 2) | 21: `TCIF2`, 20: `HTIF2`, 19: `TEIF2`, 18: `DMEIF2`, 16: `FEIF2`; бит 17 — `res` |
| 27:22 | …IF3 (поток 3) | 27: `TCIF3`, 26: `HTIF3`, 25: `TEIF3`, 24: `DMEIF3`, 22: `FEIF3`; бит 23 — `res` |
| 31:28 | `res` | Зарезервировано |

Позиции из заголовка (проверено): `FEIF0_Pos=0`, `DMEIF0_Pos=2`, `TEIF0_Pos=3`, `HTIF0_Pos=4`, `TCIF0_Pos=5`; `FEIF1_Pos=6`, `DMEIF1_Pos=8`, `TEIF1_Pos=9`, `HTIF1_Pos=10`, `TCIF1_Pos=11`; `FEIF2_Pos=16`, `DMEIF2_Pos=18`, `TEIF2_Pos=19`, `HTIF2_Pos=20`, `TCIF2_Pos=21`; `FEIF3_Pos=22`, `DMEIF3_Pos=24`, `TEIF3_Pos=25`, `HTIF3_Pos=26`, `TCIF3_Pos=27`. В `HISR` аналогично для потоков 4…7 (`FEIF4_Pos=0` … `TCIF7_Pos=27`). Флаги только читаются; гасятся через `LIFCR/HIFCR`.

## 2. DMA1/DMA2 — сброс флагов: LIFCR / HIFCR

Запись `1` в бит сброса гасит соответствующий флаг в `LISR/HISR`. Запись `0` — ничего не делает. Имена в заголовке с префиксом `C` (`CTCIF0`, `CHTIF0`, `CTEIF0`, `CDMEIF0`, `CFEIF0` …).

| Биты | Имя | Что делает |
|---|---|---|
| 5 | `CTCIF0` | Запись 1: сбросить `TCIF0` |
| 4 | `CHTIF0` | Запись 1: сбросить `HTIF0` |
| 3 | `CTEIF0` | Запись 1: сбросить `TEIF0` |
| 2 | `CDMEIF0` | Запись 1: сбросить `DMEIF0` |
| 1 | `res` | Зарезервировано |
| 0 | `CFEIF0` | Запись 1: сбросить `FEIF0` |
| 11:6 | `CTCIF1/CHTIF1/CTEIF1/CDMEIF1/CFEIF1` | То же для потока 1 (биты 11/10/9/8/6, бит 7 — `res`) |
| 15:12 | `res` | Зарезервировано |
| 21:16 | `CTCIF2/CHTIF2/CTEIF2/CDMEIF2/CFEIF2` | То же для потока 2 (биты 21/20/19/18/16, бит 17 — `res`) |
| 27:22 | `CTCIF3/CHTIF3/CTEIF3/CDMEIF3/CFEIF3` | То же для потока 3 (биты 27/26/25/24/22, бит 23 — `res`) |
| 31:28 | `res` | Зарезервировано |

`HIFCR` — то же для потоков 4…7 (`CTCIF4_Pos=5` … `CFEIF7_Pos=22`).

## 3. DMA_SxCR — конфигурация потока

Поле `CHSEL` отсутствует (выбор запроса — только через DMAMUX1). Биты 31:25 — резерв. Проверено: старшего определённого бита выше `MBURST_Pos=23` (+2 бита = 24) в заголовке нет.

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `EN` | 1 — поток включён; 0 — выключен. Сбрасывать только после `TCIF` или остановки; регистры потока править при `EN=0` |
| 1 | `DMEIE` | Разрешение прерывания по ошибке direct mode (`DMEIF`) |
| 2 | `TEIE` | Разрешение прерывания по ошибке передачи (`TEIF`) |
| 3 | `HTIE` | Разрешение прерывания половины передачи (`HTIF`) |
| 4 | `TCIE` | Разрешение прерывания конца передачи (`TCIF`) |
| 5 | `PFCTRL` | 0 — контроллер потока управляет потоком (DMA — flow controller); 1 — периферия (только если периферия умеет) |
| 7:6 | `DIR[1:0]` | Направление: `00` — периферия→память, `01` — память→периферия, `10` — память→память; `11` — `res` |
| 8 | `CIRC` | 1 — циклический режим (перезагрузка `NDTR`/`PAR`/`M0AR` автоматически) |
| 9 | `PINC` | 1 — инкремент адреса периферии после каждого обмена |
| 10 | `MINC` | 1 — инкремент адреса памяти после каждого обмена |
| 12:11 | `PSIZE[1:0]` | Размер данных периферии: `00` — 8 бит, `01` — 16 бит, `10` — 32 бита, `11` — `res` |
| 14:13 | `MSIZE[1:0]` | Размер данных памяти: `00` — 8 бит, `01` — 16 бит, `10` — 32 бита, `11` — `res` |
| 15 | `PINCOS` | Шаг инкремента периферии: 0 — по `PSIZE`, 1 — фиксировано 32 бита (двойное слово) |
| 17:16 | `PL[1:0]` | Приоритет арбитража: `00` — низкий, `01` — средний, `10` — высокий, `11` — очень высокий |
| 18 | `DBM` | 1 — двойной буфер (ping-pong `M0AR/M1AR`, текущий показывает `CT`) |
| 19 | `CT` | Текущий буфер в DBM: 0 — `M0AR`, 1 — `M1AR` (можно переключать вручную до старта) |
| 20 | `TRBUFF` | 1 — разрешить буферизуемые передачи (есть в заголовке H723; на старых сериях отсутствовал) |
| 22:21 | `PBURST[1:0]` | Burst со стороны периферии: `00` — одиночные, `01` — INCR4, `10` — INCR8, `11` — INCR16 (только с FIFO) |
| 24:23 | `MBURST[1:0]` | Burst со стороны памяти: `00` — одиночные, `01` — INCR4, `10` — INCR8, `11` — INCR16 (только с FIFO) |
| 31:25 | `res` | Зарезервировано |

## 4. DMA_SxNDTR / SxPAR / SxM0AR / SxM1AR

| Регистр | Биты | Имя | Что делает |
|---|---|---|---|
| `SxNDTR` | 15:0 | `NDT` | Остаток обменов (в единицах `PSIZE/MSIZE`). Пишется при `EN=0`; в работе уменьшается; `TCIF` при обнулении |
| `SxNDTR` | 31:16 | `res` | Зарезервировано |
| `SxPAR` | 31:0 | `PA` (`DMA_SxPAR_PA_Pos=0`) | Адрес периферии |
| `SxM0AR` | 31:0 | `M0A` (`DMA_SxM0AR_M0A_Pos=0`) | Адрес памяти 0 (или единственный буфер) |
| `SxM1AR` | 31:0 | `M1A` (`DMA_SxM1AR_M1A_Pos=0`) | Адрес памяти 1 (только DBM) |

## 5. DMA_SxFCR — FIFO

| Биты | Имя | Что делает |
|---|---|---|
| 1:0 | `FTH[1:0]` | Порог FIFO: `00` — 1/4, `01` — 1/2, `10` — 3/4, `11` — полный |
| 2 | `DMDIS` | 1 — direct mode запрещён, работает FIFO; 0 — direct mode (обход FIFO; только одиночные обмены, `MBURST/PBURST=00`) |
| 5:3 | `FS[2:0]` | Статус заполнения FIFO (только чтение): `000` — пусто … `101` — полно |
| 6 | `res` | Зарезервировано |
| 7 | `FEIE` | Разрешение прерывания по ошибке FIFO (`FEIF`) |
| 31:8 | `res` | Зарезервировано |

Позиции проверены: `FTH_Pos=0` (маска `0x3`), `DMDIS_Pos=2`, `FS_Pos=3` (маска `0x7`), `FEIE_Pos=7`.

## 6. BDMA — отличия от DMA1/DMA2

BDMA — упрощённый контроллер в домене D3 (для LPUART, I2C в низком энергопотреблении и т.п.): **8 каналов** (не потоков), **нет FIFO** (нет `SxFCR`, `DMEIF/FEIF`), направление — 1 бит, есть бит `MEM2MEM`. Структура канала: `CCR / CNDTR / CPAR / CM0AR / CM1AR` (те же смещения, что у DMA-потока без `FCR`).

`BDMA_ISR` (чтение) / `BDMA_IFCR` (сброс записью 1): каждый канал занимает 4 бита подряд, без резервов: `GIFx = 4x`, `TCIFx = 4x+1`, `HTIFx = 4x+2`, `TEIFx = 4x+3` (проверено: `GIF0_Pos=0`, `TCIF0_Pos=1`, `HTIF0_Pos=2`, `TEIF0_Pos=3`, …, `GIF7_Pos=28`, `TEIF7_Pos=31`; в `IFCR` те же позиции с префиксом `C`: `CGIFx/CTCIFx/CHTIFx/CTEIFx`).

`BDMA_CCR`:

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `EN` | Включение канала |
| 1 | `TCIE` | Прерывание по `TCIF` |
| 2 | `HTIE` | Прерывание по `HTIF` |
| 3 | `TEIE` | Прерывание по `TEIF` |
| 4 | `DIR` | 0 — чтение из периферии (периферия→память), 1 — чтение из памяти (память→периферия) |
| 5 | `CIRC` | Циклический режим |
| 6 | `PINC` | Инкремент адреса периферии |
| 7 | `MINC` | Инкремент адреса памяти |
| 9:8 | `PSIZE[1:0]` | Размер периферии: `00` — 8 бит, `01` — 16 бит, `10` — 32 бита |
| 11:10 | `MSIZE[1:0]` | Размер памяти: `00` — 8 бит, `01` — 16 бит, `10` — 32 бита |
| 13:12 | `PL[1:0]` | Приоритет: `00` — низкий … `11` — очень высокий |
| 14 | `MEM2MEM` | 1 — режим память→память |
| 15 | `DBM` | 1 — двойной буфер (`CM0AR/CM1AR`, текущий — `CT`) |
| 16 | `CT` | Текущий буфер: 0 — `CM0AR`, 1 — `CM1AR` |
| 31:17 | `res` | Зарезервировано |

`BDMA_CNDTR`: `NDT` биты 15:0, `res` 31:16. `BDMA_CPAR/CM0AR/CM1AR` — полный 32-битный адрес (`PA/MA`, `Pos=0`).

## 7. MDMA — кратко (16 каналов, linked list, триггеры)

MDMA висит на D1 (`0x52000000`), каналов **16** (не 1): `MDMA_Channeln_BASE = MDMA_BASE + 0x40 + n*0x40`. Общий `GISR0` (`GIF0…GIF15`, по биту на канал). Ключевые отличия: дескрипторы в памяти (linked list через `CLAR`), аппаратный триггер старта (`TSEL/TRGM`), блочные передачи с повтором (`BRC`), маскированные операции и выбор шин (`SBUS/DBUS`).

`MDMA_CISR` (статус) / `MDMA_CIFCR` (сброс записью 1):

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `TEIF/CTEIF` | Ошибка передачи; сброс битом `CTEIF` |
| 1 | `CTCIF/CCTCIF` | Конец передачи канала; сброс `CCTCIF` |
| 2 | `BRTIF/CBRTIF` | Конец блока с повтором; сброс `CBRTIF` |
| 3 | `BTIF/CBTIF` | Конец блока; сброс `CBTIF` |
| 4 | `TCIF/CLTCIF` | Конец дескриптора linked list; сброс `CLTCIF` |
| 15:5 | `res` | Зарезервировано |
| 16 | `CRQA` | Запрос канала активен (только чтение, только в `CISR`) |
| 31:17 | `res` | Зарезервировано |

`MDMA_CESR` (ошибки, только чтение/флаги): `TEA[6:0]` — адрес ошибки (биты 6:0), `TED` (7) — ошибка данных, `TELD` (8) — ошибка linked-list данных, `TEMD` (9) — ошибка маски, `ASE` (10) — ошибка размера адреса, `BSE` (11) — ошибка размера блока; биты 31:12 — `res`.

`MDMA_CCR`:

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `EN` | Включение канала |
| 1 | `TEIE` | Прерывание по ошибке |
| 2 | `CTCIE` | Прерывание конца передачи канала |
| 3 | `BRTIE` | Прерывание конца блока с повтором |
| 4 | `BTIE` | Прерывание конца блока |
| 5 | `TCIE` | Прерывание конца дескриптора (linked list) |
| 7:6 | `PL[1:0]` | Приоритет |
| 11:8 | `res` | Зарезервировано |
| 12 | `BEX` | Обмен байтами в полуслове |
| 13 | `HEX` | Обмен полусловами |
| 14 | `WEX` | Обмен словами |
| 15 | `res` | Зарезервировано |
| 16 | `SWRQ` | Программный запрос (запись 1 — старт передачи) |
| 31:17 | `res` | Зарезервировано |

`MDMA_CTCR` (конфигурация передачи):

| Биты | Имя | Что делает |
|---|---|---|
| 1:0 | `SINC[1:0]` | Инкремент источника: `00` — фикс., `01` — по размеру, `10` — декремент, `11` — `res` |
| 3:2 | `DINC[1:0]` | То же для приёмника |
| 5:4 | `SSIZE[1:0]` | Размер источника: `00` — 8 бит, `01` — 16, `10` — 32, `11` — 64 бита |
| 7:6 | `DSIZE[1:0]` | Размер приёмника: аналогично |
| 9:8 | `SINCOS[1:0]` | Шаг инкремента источника (offset size) |
| 11:10 | `DINCOS[1:0]` | Шаг инкремента приёмника |
| 14:12 | `SBURST[2:0]` | Burst источника (0 — одиночные … до 128) |
| 17:15 | `DBURST[2:0]` | Burst приёмника |
| 24:18 | `TLEN[6:0]` | Длина передаваемого блока − 1 |
| 25 | `PKE` | Включить упаковку/выравнивание (pack enable) |
| 27:26 | `PAM[1:0]` | Режим выравнивания при упаковке |
| 29:28 | `TRGM[1:0]` | Режим триггера: `00` — программный/полный, `01` — по событию — блок, `10/11` — linked-list режимы |
| 30 | `SWRM` | Режим программной записи маски |
| 31 | `BWM` | Режим побайтовой записи маски |

Остальные регистры канала (все `Pos=0`, полная ширина, кроме указанных):

| Регистр (смещение) | Биты | Имя | Что делает |
|---|---|---|---|
| `CBNDTR` (+0x54) | 16:0 | `BNDT` | Число данных в блоке |

| `CDAR` (+0x5C) | 31:0 | `DAR` | Адрес приёмника |
| `CBRUR` (+0x60) | 15:0 | `SUV` | Шаг обновления источника при повторе блока |
| `CBRUR` | 31:16 | `DUV` | Шаг обновления приёмника при повторе блока |
| `CLAR` (+0x64) | 31:0 | `LAR` | Адрес следующего дескриптора (linked list; 0 — конец) |

| `CMDR` (+0x74) | 31:0 | `MDR` | Данные маски |

## 8. DMAMUX1 — мультиплексор запросов (обязательно)

16 каналов `CxCR` (`DMAMUX1_Channeln_BASE = DMAMUX1_BASE + n*4`, n = 0…15): канал мультиплексора `n` обслуживает поток DMA `n` (первые 8 — DMA1, остальные — DMA2; точное соответствие — по RM). Плюс 8 генераторов запроса `RGxCR` (сигналы `SIG_ID`, счётчик `GNBREQ`).

`DMAMUX_CxCR`:

| Биты | Имя | Что делает |
|---|---|---|
| 7:0 | `DMAREQ_ID[7:0]` | Номер запроса от периферии (таблица — в RM; `0` — нет запроса). Главная настройка: без неё поток не получит триггер |
| 8 | `SOIE` | Прерывание по переполнению синхронизации (`SOFx`) |
| 9 | `EGE` | 1 — генерация события при срабатывании (для связки с другими блоками) |
| 15:10 | `res` | Зарезервировано |
| 16 | `SE` | 1 — включить вход синхронизации (sync) для этого канала |
| 18:17 | `SPOL[1:0]` | Полярность sync: `00` — без детектирования, `01` — по фронту, `10` — по спаду, `11` — по обоим |
| 23:19 | `NBREQ[4:0]` | Число запросов DMA после события sync минус 1 (1…32) |
| 28:24 | `SYNC_ID[4:0]` | Выбор источника сигнала синхронизации (таблица — в RM) |
| 31:29 | `res` | Зарезервировано |

Статус/очистка sync-переполнений: `DMAMUX_CSR` — флаги `SOF0…SOF15` (бит = номер канала), `DMAMUX_CFR` — сброс записью 1 `CSOF0…CSOF15`. Позиции проверены (`SOF0_Pos=0 … SOF15_Pos=15`).

`DMAMUX_RGxCR` (генератор запроса n = 0…7):

| Биты | Имя | Что делает |
|---|---|---|
| 4:0 | `SIG_ID[4:0]` | Выбор входного сигнала-триггера генератора (таблица — в RM) |
| 7:5 | `res` | Зарезервировано |
| 8 | `OIE` | Прерывание по переполнению генератора (`OFx`) |
| 15:9 | `res` | Зарезервировано |
| 16 | `GE` | 1 — генератор включён |
| 18:17 | `GPOL[1:0]` | Полярность детектирования: `00` — без детектирования, `01` — фронт, `10` — спад, `11` — оба |
| 23:19 | `GNBREQ[4:0]` | Число генерируемых запросов минус 1 (1…32) |
| 31:24 | `res` | Зарезервировано |

Статус/очистка: `DMAMUX_RGSR` — флаги `OF0…OF7`, `DMAMUX_RGCFR` — сброс записью 1 `COF0…COF7`.

## 9. Минимальный порядок запуска потока DMA (память→периферия)

1. Выключить поток: `SxCR.EN = 0`, дождаться `EN == 0`.
2. Погасить флаги потока: записать 1 в нужные биты `LIFCR/HIFCR` (`CTCIFx/CHTIFx/CTEIFx/CDMEIFx/CFEIFx`).
3. Запрограммировать `SxPAR`, `SxM0AR`, `SxNDTR`, поля `SxCR` (`DIR=01`, `MINC=1`, `PSIZE/MSIZE`, `TCIE/TEIE` при нужде).
4. Настроить FIFO (`SxFCR.DMDIS/FTH`) или оставить direct mode (`DMDIS=0`, bursts `00`).
5. Выбрать запрос в DMAMUX1: `CxCR.DMAREQ_ID = <id периферии>` (плюс `SYNC_ID/NBREQ`, если нужен sync).
6. Включить поток: `SxCR.EN = 1`. Флаг `TCIFx` — конец; гасится битом `CTCIFx` в `LIFCR/HIFCR`.
