# I2C — справочник регистров (STM32H723VGT6, CMSIS, без HAL)

Источник позиций/ширин бит: `Inc/stm32h723xx.h` (проверено grep по `I2C_CR1_*_Pos`, `I2C_CR2_*_Pos`, `I2C_OAR1/OAR2_*_Pos`, `I2C_TIMINGR/TIMEOUTR_*_Pos`, `I2C_ISR/ICR_*_Pos`, `I2C_PECR/RXDR/TXDR_*_Pos` + структ `I2C_TypeDef` для смещений).
Формат: заголовок, таблицы `| Биты | Имя | Что делает |`, строки `res`, русский язык.

Базовые адреса (из заголовка):

| Модуль | База |
|---|---|
| I2C1 | 0x40005400 (`D2_APB1 + 0x5400`) |
| I2C2 | 0x40005800 (`D2_APB1 + 0x5800`) |
| I2C3 | 0x40005C00 (`D2_APB1 + 0x5C00`) |
| I2C5 | 0x40006400 (`D2_APB1 + 0x6400`) |
| I2C4 | 0x58001C00 (`D3_APB1 + 0x1C00`) |

Смещения (`I2C_TypeDef`): CR1 0x00, CR2 0x04, OAR1 0x08, OAR2 0x0C, TIMINGR 0x10, TIMEOUTR 0x14, ISR 0x18, ICR 0x1C, PECR 0x20, RXDR 0x24, TXDR 0x28.

Общее правило: TIMINGR/OAR/CR1(SMBus-биты) настраивать при `PE=0`. CR2.`START/STOP/NBYTES` — при `PE=1`.

## CR1 (0x00) — контроль 1

| Биты | Имя | Что делает |
|---|---|---|
| 0 | PE | 1 = модуль включён. TIMINGR/OAR менять при `PE=0` |
| 1 | TXIE | Прерывание по `ISR.TXIS` (нужно писать следующий байт) |
| 2 | RXIE | Прерывание по `ISR.RXNE` (пришёл байт) |
| 3 | ADDRIE | Прерывание по `ISR.ADDR` (slave: совпал свой адрес) |
| 4 | NACKIE | Прерывание по `ISR.NACKF` (получен NACK) |
| 5 | STOPIE | Прерывание по `ISR.STOPF` (детект STOP) |
| 6 | TCIE | Прерывание по `ISR.TC` (передано `NBYTES`, идёт RELOAD-продолжение) |
| 7 | ERRIE | Прерывания ошибок: `BERR/ARLO/OVR/PECERR/TIMEOUT/ALERT` |
| 11:8 | DNF | Цифровой фильтр: `0=выкл, 1–15=число тактов `i2c_ker_ck` для подавления глитчей` |
| 12 | ANFOFF | 1 = выключить аналоговый фильтр (по умолчанию 0 = включён) |
| 13 | `res` | Зарезервирован |
| 14 | TXDMAEN | 1 = DMA-запрос на передачу (`TXIS`) |
| 15 | RXDMAEN | 1 = DMA-запрос на приём (`RXNE`) |
| 16 | SBC | Slave byte control: 1 = slave сам решает NACK на каждый байт (через `CR2.NACK`), вместо авто-ACK |
| 17 | NOSTRETCH | 1 = запретить clock stretching в slave (иначе slave тянет SCL пока не готов) |
| 18 | WUPEN | 1 = пробуждение из Stop по адресу (нужен HSI) |
| 19 | GCEN | 1 = slave отвечает на General Call (0x00) |
| 20 | SMBHEN | 1 = режим SMBus Host (ответ на 0x08, slave) |
| 21 | SMBDEN | 1 = режим SMBus Device (ответ на 0x61 по умолчанию, slave) |
| 22 | ALERTEN | 1 = slave поддерживает SMBus ALERT (пин SMBA) |
| 23 | PECEN | 1 = включён PEC (CRC-8, полином x^8+x^2+x+1), байт PEC — через `PECBYTE`/авто |
| 31:24 | `res` | Зарезервированы |

## CR2 (0x04) — контроль 2 (адрес + число байт + старт/стоп)

| Биты | Имя | Что делает |
|---|---|---|
| 9:0 | SADD | Адрес slave: биты 9:0. Для 7-бит — пиши в `SADD[7:1]`, бит 0 не важен; для 10-бит — все 10 бит |
| 10 | RD_WRN | Направление master: `0=write (TX), 1=read (RX)` |
| 11 | ADD10 | 1 = 10-битный адрес, 0 = 7-битный |
| 12 | HEAD10R | Только 10-бит read: 1 = только перезапуск read-фазы (уже была write-фаза адреса), 0 = полный цикл |
| 13 | START | Запись 1 = выдать START (+ адрес). Железо сбрасывает в 0 после рассылки адреса |
| 14 | STOP | Запись 1 = выдать STOP после текущего байта (или сразу если `TXE=1`). Железо сбрасывает после STOP |
| 15 | NACK | Запись 1 = послать NACK после текущего байта (slave или master-приёмник). 0 = ACK |
| 23:16 | NBYTES | Число байт в текущей фазе (`0–255`). При `RELOAD=0/AUTOEND=1` — вся длина; при длинных — чанки по 255 |
| 24 | RELOAD | 1 = после `NBYTES` будет продолжение (`ISR.TCR=1`, а не `TC`), надо записать новые `NBYTES` без повторного START |
| 25 | AUTOEND | 1 = после `NBYTES` железо само выдаст STOP (вместо ожидания софта). Не ставить вместе с `RELOAD=1` |
| 26 | PECBYTE | 1 = в этой фазе последним байтом идёт PEC (авто-проверка/отправка при `PECEN=1`) |
| 31:27 | `res` | Зарезервированы |

## OAR1 (0x08) / OAR2 (0x0C) — собственные адреса slave

OAR1:

| Биты | Имя | Что делает |
|---|---|---|
| 9:0 | OA1 | Собственный адрес 1 (7-бит: `OA1[7:1]`; 10-бит: `OA1[9:0]`) |
| 10 | OA1MODE | 0 = 7-бит, 1 = 10-бит (для OA1) |
| 14:11 | `res` | Зарезервированы |
| 15 | OA1EN | 1 = адрес 1 включён |
| 31:16 | `res` | Зарезервированы |

OAR2:

| Биты | Имя | Что делает |
|---|---|---|
| 0 | `res` | Зарезервирован (младший бит не используется) |
| 7:1 | OA2 | Собственный адрес 2 (только 7-бит) |
| 10:8 | OA2MSK | Маска адреса 2 (какие биты игнорировать): `0=без маски, 1=маска 1 бит … 7=маска всех 7 бит`. В заголовке также алиасы `OA2MASK01..07` — это те же биты 10:8 по отдельности |
| 14:11 | `res` | Зарезервированы |
| 15 | OA2EN | 1 = адрес 2 включён |
| 31:16 | `res` | Зарезервированы |

Прим.: `GCEN` (ответ на 0x00) — в CR1, а не в OAR (в задаче упомянут рядом с OAR — уточнено по заголовку: `I2C_CR1_GCEN_Pos=19`).

## TIMINGR (0x10) — тайминги (настраивать при PE=0)

| Биты | Имя | Что делает |
|---|---|---|
| 7:0 | SCLL | Длительность низкого SCL минус 1: `t_SCLL = (SCLL+1) * t_PRESC` |
| 15:8 | SCLH | Длительность высокого SCL минус 1: `t_SCLH = (SCLH+1) * t_PRESC` |
| 19:16 | SDADEL | Задержка данных после спада SCL (удержание SDA): `t_SDADEL = SDADEL * t_PRESC` (защита от hold-нарушений) |
| 23:20 | SCLDEL | Задержка SDA перед фронтом SCL (setup): `t_SCLDEL = (SCLDEL+1) * t_PRESC` |
| 27:24 | `res` | Зарезервированы |
| 31:28 | PRESC | Предделитель: `t_PRESC = (PRESC+1) * t_i2c_ker_ck` |

Формулы (RM): период SCL ≈ `(SCLH+1 + SCLL+1) * (PRESC+1) / f_ker`. Примеры-старты (проверять осциллографом/анализатором, точные значения зависят от `f_ker`, ёмкости шины и аналогового фильтра):
- 100 кГц при `f_ker=80 МГц`: типично `PRESC=7, SCLL≈0xC7, SCLH≈0xC3, SDADEL≈0x02, SCLDEL≈0x04` (порядок, не догма);
- 400 кГц при `f_ker=80 МГц`: типично `PRESC=3, SCLL≈0x09, SCLH≈0x03, SDADEL≈0x02, SCLDEL≈0x03`.
Рекомендация ST: считать через STM32CubeMX / таблицу RM под конкретный `f_ker` ( img `I2CCLK`), затем проверить `SCLDEL ≥ t_r(max)`, `SDADEL ≥ t_f(max)` с учётом фильтра.

## TIMEOUTR (0x14) — таймауты SMBus

| Биты | Имя | Что делает |
|---|---|---|
| 11:0 | TIMEOUTA | Значение таймаута A (SCL низкий слишком долго / кумулятивный): `(TIMEOUTA+1) * 2048 * t_i2c_ker_ck` |
| 12 | TIDLE | 0 = TIMEOUTA = время низкого SCL (SCL low timeout), 1 = TIMEOUTA = время простоя шины (оба SCL+SDA высоки) |
| 14:13 | `res` | Зарезервированы |
| 15 | TIMOUTEN | 1 = включён таймаут A (внимание: в заголовке опечатка `TIMOUTEN` без `E` — `I2C_TIMEOUTR_TIMOUTEN_Pos=15`) |
| 27:16 | TIMEOUTB | Значение расширенного таймаута B (кумулятивный): `(TIMEOUTB+1) * 2048 * t_i2c_ker_ck` |
| 30:28 | `res` | Зарезервированы |
| 31 | TEXTEN | 1 = включён расширенный (кумулятивный) таймаут B |

Прим.: в задаче упомянуто `TIMEOUTEN` — в заголовке бит называется `TIMOUTEN` (15) и отдельно `TEXTEN` (31); `TIDLE` — один бит 12, второго `TIDLE?` нет.

## ISR (0x18) — статус (как гасится каждый флаг)

| Биты | Имя | Что делает / как гасится |
|---|---|---|
| 0 | TXE | TX пуст (можно писать, но фаза ещё не требует). Только чтение; гаснет записью в `TXDR` |
| 1 | TXIS | Надо писать следующий байт (TX interrupt status). Гаснет записью в `TXDR` |
| 2 | RXNE | Пришёл байт в приёмник. Гаснет чтением `RXDR` |
| 3 | ADDR | Slave: совпал адрес, `ADDCODE/DIR` валидны. Гаснет записью `ICR.ADDRCF=1` |
| 4 | NACKF | Получен NACK. Гаснет записью `ICR.NACKCF=1` |
| 5 | STOPF | Детект STOP. Гаснет записью `ICR.STOPCF=1` |
| 6 | TC | Передано `NBYTES` и `RELOAD=0`: фаза окончена (при `AUTOEND=0` ждёт `STOP`, при `AUTOEND=1` STOP уже пошёл). Гаснет записью `START`/`STOP` в CR2 |
| 7 | TCR | Передано `NBYTES` и `RELOAD=1`: надо записать следующие `NBYTES` (продолжение без START). Гаснет записью новых `NBYTES` |
| 8 | BERR | Ошибка шины (нелегальный START/STOP). Гаснет `ICR.BERRCF=1` |
| 9 | ARLO | Потеря арбитража. Гаснет `ICR.ARLOCF=1` |
| 10 | OVR | Overrun/underrun. Гаснет `ICR.OVRCF=1` |
| 11 | PECERR | Ошибка PEC. Гаснет `ICR.PECCF=1` |
| 12 | TIMEOUT | Сработал таймаут. Гаснет `ICR.TIMOUTCF=1` (в заголовке `TIMOUTCF` без `E`) |
| 13 | ALERT | SMBus ALERT. Гаснет `ICR.ALERTCF=1` |
| 14 | `res` | Зарезервирован |
| 15 | BUSY | 1 = шина занята (идёт трафик). Только чтение |
| 16 | DIR | Направление текущей фазы (slave): `0=write, 1=read`. Валиден при `ADDR=1`. Только чтение |
| 23:17 | ADDCODE | Адрес, который совпал (slave). Только чтение |
| 31:24 | `res` | Зарезервированы |

## ICR (0x1C) — сброс флагов (пиши 1)

| Биты | Имя | Что делает |
|---|---|---|
| 2:0 | `res` | Зарезервированы |
| 3 | ADDRCF | 1 = сбросить `ADDR` |
| 4 | NACKCF | 1 = сбросить `NACKF` |
| 5 | STOPCF | 1 = сбросить `STOPF` |
| 7:6 | `res` | Зарезервированы |
| 8 | BERRCF | 1 = сбросить `BERR` |
| 9 | ARLOCF | 1 = сбросить `ARLO` |
| 10 | OVRCF | 1 = сбросить `OVR` |
| 11 | PECCF | 1 = сбросить `PECERR` |
| 12 | TIMOUTCF | 1 = сбросить `TIMEOUT` (имя из заголовка без `E`) |
| 13 | ALERTCF | 1 = сбросить `ALERT` |
| 31:14 | `res` | Зарезервированы |

## PECR (0x20) / RXDR (0x24) / TXDR (0x28)

| Регистр | Биты | Имя | Что делает |
|---|---|---|---|
| PECR | 7:0 | PEC | Текущий/принятый PEC-байт (при `PECEN=1`). Только младшие 8 бит |
| PECR | 31:8 | `res` | Зарезервированы |
| RXDR | 7:0 | RXDATA | Принятый байт. Чтение гасит `RXNE` |
| RXDR | 31:8 | `res` | Зарезервированы |
| TXDR | 7:0 | TXDATA | Байт на передачу. Запись гасит `TXIS/TXE` |
| TXDR | 31:8 | `res` | Зарезервированы |

## Алгоритмы master (RELOAD / AUTOEND / NBYTES)

Подготовка (один раз): `PE=0` → `TIMINGR` → `PE=1`.

### Master write (N ≤ 255, AUTOEND)

1. `CR2 = (addr<<0) | (N<<16) | (0<<10 RD_WRN) | (0<<11 ADD10) | (0<<24 RELOAD) | (1<<25 AUTOEND) | (1<<13 START)`.
2. Цикл: ждать `TXIS==1` → писать `TXDR`. Ошибка `NACKF` → `NACKCF`, выход.
3. Ждать `STOPF==1` (авто-STOP отработал) → `STOPCF=1`. Готово.

### Master write длинный (N > 255, RELOAD)

1. `CR2 = addr | (255<<16) | WRITE | RELOAD=1 | AUTOEND=0 | START`.
2. Передать 255 через `TXIS/TXDR`. Ждать `TCR==1` (не `TC`!).
3. Дописать `CR2.NBYTES = min(остаток,255)`; если это последний чанк — `RELOAD=0, AUTOEND=1`, иначе `RELOAD=1`.
4. Повторять 2–3 до конца. В конце ждать `STOPF` → `STOPCF`.

### Master read (N ≤ 255, AUTOEND)

1. `CR2 = (addr<<0) | (N<<16) | (1<<10 RD_WRN) | AUTOEND=1 | START`.
2. Цикл: ждать `RXNE==1` → читать `RXDR`. (При `N==1` первый байт уже может ждать.)
3. Ждать `STOPF==1` → `STOPCF=1`.

### Master read длинный — аналогично write, но через `RXNE/RXDR` и `TCR` между чанками.

Псевдокод write (CMSIS):
```c
I2C1->CR2 = (addr << 0) | (n << 16) | (0u << 10) | (1u << 25) | (1u << 13); // AUTOEND+START
for (i = 0; i < n; i++) {
    while (!(I2C1->ISR & (1u << 1))) { if (I2C1->ISR & (1u << 4)) goto nack; } // TXIS / NACKF
    I2C1->TXDR = buf[i];
}
while (!(I2C1->ISR & (1u << 5))); // STOPF
I2C1->ICR = (1u << 5);            // STOPCF
```
